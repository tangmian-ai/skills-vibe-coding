# Skill C1 · Brand Kit 推导

## 原则
- **色彩不预设，由被营销的产品决定**；工作台对任何品牌/平台中立，**禁止硬编码平台 VI**（如不对所有项目默认某品牌红）
- 两条路径：`import`（品牌方已有 VI，直接导入）/ `derive`（无 VI，按下表推导）
- 推导结果 = **提案**，设计师在 H1 确认后才锁定，且**仅本项目生效**

## derive 推导链
```
产品品类 + 目标人群 + 品牌定位
→ 品牌人格（荣格 12 原型，主 + 辅）
→ 社交身份短语（[形容词]+[身份名词]）
→ 色彩气质 → 具体色板提案（主色/深色/底色/辅助）
→ 字体气质（黑体系=现代高效 / 衬线系=质感人文 / 圆体系=亲和童趣）
```

## derive 分析框架（来自内部品牌设计 SOP 第一步）
信息不全时按品牌名/行业/产品合理推导，**推导项必须标注为 AI 建议**，进 H1 由人确认。

**1. 品牌关键词五分类**（比单一风格词更可控的提示词来源）：
`商业关键词 / 视觉关键词 / 情绪关键词 / 材质关键词 / 场景关键词`

**2. 参考品牌拆解**（3~5 个同赛道品牌）：
- 只学视觉逻辑（LOGO 形式/色彩系统/字体/辅助图形/包装/社媒视觉的规律），
  **不复制** LOGO、字体、图形、版式、广告语
- 同时输出行业同质化风险 → 本品牌应避开的方向 + 差异化机会点

**3. 三方向提案给 H1**（替代单一提案，给人可选项）：
| 方向 | 定位 |
|------|------|
| 稳妥商业型 | 贴行业主流审美，风险最低 |
| 高端差异型 | 低饱和克制、留白质感，抬客单价感知 |
| 年轻传播型 | 高饱和/强符号，社媒传播优先 |

每方向输出：视觉关键词 / 色彩建议 / 字体建议 / 辅助图形建议 / 优势与风险，
并附**推荐方向 + 推荐理由**（H1 可直接采纳或改选）。

## 品类 → 色彩气质速查
| 品类 | 常见气质 | 色板方向示例 |
|------|---------|-------------|
| 母婴/家庭 | 温柔·安心 | 奶油暖色 + 低饱和点缀 |
| 科技/工具 | 专业·先锋 | 冷色高对比 / 深底荧光点缀 |
| 美妆/护肤 | 精致·信任 | 按定位分：药妆冷白 / 彩妆高饱和 |
| 食品/餐饮 | 食欲·烟火气 | 暖色系 + 高明度 |
| 高客单/轻奢 | 静谧·克制 | 低饱和大地色 + 大留白 |

## 输出格式（提案给 H1）
```yaml
brand_kit_proposal:
  source: derive | import
  persona: { main: 原型, aux: 原型, identity: "身份短语" }
  color: { primary: "#", dark: "#", bg: "#", accent: "#" }
  typography: { display: "", body: "" }
  style_keywords: [3~5 个]
  tone_of_voice: ""
  rationale: "为什么这样推导（一段话）"
```

## 锁定后的效力
- 所有 Agent 出图/出文案必须引用已锁定 Kit，禁止流程中途换色
- 跨项目不继承；同品牌新项目默认读取历史 Kit 并询问是否沿用
