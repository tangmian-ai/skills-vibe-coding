# 小红书人像封面生成 Skill

## 1. Prompt 生成核心结构

**核心作用说明**：
本模块是将**用户输入的需求**（显性指令）与 **Agent 的策略思考**（隐性规则）进行深度融合并格式化的最终出口。
Agent 必须在此处将抽象的分析结果（如版式选择、色彩推演）转化为 Seedream 模型可直接执行的具体绘画指令。请严格按照下述结构进行**按需填空**，确保输出的 Prompt 既精准响应用户意图，又符合小红书爆款视觉标准。

（Agent 注意：以下结构为 Seedream 模型生图专用标准语法。请严格按照下述格式输出，不要携带任何警告或分析文字。若用户未提及则删除此行（例如：辅助文案）。请务必将括号 `[...]` 内的说明文字替换为您实际生成的具体描述，切勿照抄说明指令。）

```text
(素人原生感),(真实日常场景),（生活化手机实拍质感）。

[海报主题]：[此处填入用户的主题，超精简概括，不超过10个字]。

[人物维度]：[性别/着装] + [表情] + [手部动作细节/腿部动作] + [景别：全身/半身/胸像/特写] + [拍摄角度]。

[背景维度]：[与主题相关的真实场景截取，干净不杂乱],适当虚化处理。

[装饰元素]：[列举画面中出现的所有装饰元素，并描述其风格质感，如：红色手绘风笔触圈圈、3D立体光泽感箭头、扁平化气泡框]。

[文案信息]：[主标题：内容] + [副标题：内容] + [辅助文案1：xxx] + [辅助文案2：xxx]。

[版式框架]：[顶部区域：主标题的具体排布方式] + [中部区域：人物位置 + 辅助文案/装饰元素的具体空间坐标坐标] + [底部区域：副标题排布方式]。（注意：必须涵盖文案信息中列举的所有元素，确保视觉平衡）。

[字体样式]：[主标题：文案+字号+颜色字体+描边/阴影效果] + [副标题：文案+字号+颜色字体+样式细节] + [辅助文案：文案+极小字号+颜色字体+标签框样式]。

[图层前后关系]：[明确排列顺序，例如：辅助文案 > 人物 > 主标题 > 背景]。

[整体风格]：[日常实拍写实质感，高点击率社交媒体封面风格，高清晰度。]

[画面比例]：3:4。

```

## 2. 核心交互流程

在执行具体生成逻辑前，Agent 必须严格按照以下【条件分支逻辑】进行交互：

**第一阶段：文案确认阶段**
1.  **意图判断与文案生成**：
    - **👉 IF (如果) 用户明确指定了最终文案内容**（必须包含“主标题为：xxx”或“文案确定为：xxx”等指意明确的词汇）：
      - **注意**：若用户仅提供“内容主题：xxx”或“我想做一个xxx的主题”，这属于模糊意图，严禁跳过，必须执行 ELSE 分支生成方案供用户挑选。
      - **【强制动作】**：跳过文案生成，直接进入【步骤 4】进行信息映射。
    - **👉 ELSE (否则) 用户只给了宽泛的主题或想法，未提供具体标题**：
      - **【强制动作】**：必须优先调用 `references/文案专家指南/skill.md`，生成 3 条不同风格的爆款文案方案，内容包含主标题，副标题。
2.  **用户确认**：（⚠️仅在执行了上述 ELSE 分支时触发此步）展示生成的 3 条方案，并调用询问工具让用户选择哪一条。需提示用户确认文案、画面细节后，会执行生图，避免用户误以为只是文案生成工具。沟通风格活泼。

**第二阶段：画面构建阶段**
4.  **信息映射**：将前三步整理出来的**最终文案内容**严格映射到 **Prompt 生成核心结构** 的 `[文案信息]` 维度。
5.  **封面生成**：利用最终填充完整的 Prompt，**直接调用 Seedream 4.5 模型**进行封面生成。**注意：Prompt 生成后必须立即调用模型生成图片，不可中断流程。且调用时必须指定 `aspect_ratio="3:4"` 参数。** 首次封面生成后，需提示用户是否还有要修改的地方。

## 3. 用户创作场景触发与执行逻辑

本模块的核心目的是让 Agent 精准理解用户创作场景的触发条件（如图片数量、指令关键词），以及在执行过程中对 Prompt 结构的处理条件（如强制替换、风格复刻、自动生成）。
**通用规则**：所有生成逻辑必须严格遵循 `references/设计原则与标准.md` 中的**品质标准**与 `references/爆款生成公式.md` 中的**爆款公式**。

### 模式 A：🎨 同款封面复刻
- **触发**：2图（人物图+参考图）+ 文案。
- **逻辑**：
  1.  **强制替换项**：
      - **人物** (`[人物维度]`)：默认保持参考图1人物形象，着装，表情，动作，若用户有明确修改指令（如“改动作，与图2保持一致”），则优先执行指令。
      - **内容** (`[海报主题]` + `[文案信息]`)：严格执行**文案确认阶段**最终确认的主题与文案信息。
      - **氛围** (`[背景维度]` + `[装饰元素]`)：基于新主题重新设计，**严禁**照搬图2。
  2.  **风格复刻项**：
      - **排版构图** (`[版式框架]`)：完全照搬图2的结构布局。
      - **字体样式** (`[字体样式]`)：完全照搬图2的字体风格/特效。
      - **图层关系** (`[图层前后关系]`)：完全照搬图2的遮挡逻辑。
      - **配色逻辑** (`[画面配色]`)：完全照搬图2的配色方案。

### 模式 B：✍️ 博主风封面定制
- **触发**：1图（人物图）+ 文案。
- **逻辑**：
  1.  **强制定义项**：
      - **人物** (`[人物维度]`)：基于图1特征（FaceID），**按需响应用户指令**调整子维度。若用户无指令，**绝对保持图1**的动作与表情，严禁脑补不存在的动作/视线。
      - **内容** (`[海报主题]` + `[文案信息]`)：应用用户提供的文案与主题。
  2.  **风格生成项**：
      - **氛围/背景/装饰** (`[背景维度]`+`[装饰元素]`)：**必须**综合参考 `references/爆款生成公式.md`，结合用户主题生成。
      - **视觉风格** (`[版式框架]`+`[字体样式]`+`[画面配色]`)：调用 `references/爆款生成公式.md` 中的爆款公式生成。

### 模式 C：💬 虚拟IP封面定制
- **触发**：0图 + 文案。
- **逻辑**：
  1.  **强制定义项**：
      - **内容** (`[海报主题]` + `[文案信息]`)：应用用户提供的文案与主题。
  2.  **风格生成项**：
      - **人物** (`[人物维度]`)：
        - **👉 IF (如果) 用户指定虚拟/卡通形象**：调用 `references/行业人像特征/references/虚拟角色.md` 并结合 `references/行业人像特征/skill.md` 确定动作场景。
        - **👉 ELSE IF (如果) 用户指定真实人像**：调用 `references/行业人像特征/skill.md` 根据赛道规则生成。
    - **👉 ELSE (默认)**：若无明确要求，**默认生成虚拟卡通形象**，需同时调用 `references/行业人像特征/references/虚拟角色.md`。
      - **氛围/背景/装饰** (`[背景维度]`+`[装饰元素]`)：**必须**综合参考 `references/爆款生成公式.md`，结合用户主题生成。
      - **视觉风格** (`[版式框架]`+`[字体样式]`+`[画面配色]`)：调用 `references/爆款生成公式.md` 中的爆款公式生成。

## 4. Prompt结构化填充流程

Agent 在执行具体的 Prompt 生成任务时，必须严格遵循以下 **三步构建流程**，确保从信息锁定到公式化生成的逻辑闭环。

### 第一步：信息整合
- **动作**：整理并锁定**文案确认阶段**最终确认的文案信息与核心主题，作为 Prompt 生成的唯一内容源。

### 第二步：设计原则内化
- **动作**：调用 `references/设计原则与标准.md` 中的核心设计知识，掌握高点击率封面的视觉逻辑。

### 第三步：公式化生成
- **动作**：结合 `references/爆款生成公式.md`，严格按照 `1. Prompt 生成核心结构` 进行一比一精准填充。

## 5. 知识库索引

Agent 在执行任务时，请根据以下指引调用对应的 Reference 文件：

- **设计美学与标准**：调用 `references/设计原则与标准.md`
  - 用途：获取配色、排版、字体选择等通用设计原则。
  - 调用时机：在【Prompt结构化填充流程】的【第二步：设计原则内化】中调用。

- **行业人像特征**：调用 `references/行业人像特征/skill.md`
  - 用途：获取特定行业赛道（职场、校园、自媒体等）的人像生成规则。
  - 调用时机：在【用户创作场景触发与执行逻辑】中，根据用户指定的行业调用对应规则。
  - **特别说明**：若命中虚拟形象需求，需额外调用 `references/行业人像特征/references/虚拟角色.md`。

- **爆款生成公式**：调用 `references/爆款生成公式.md`
  - 用途：获取 Prompt 各字段（如海报主题、人物维度、装饰元素）的具体填充策略。
  - 调用时机：在【Prompt结构化填充流程】的【第三步：公式化生成】中调用。

- **文案专家指南**：调用 `references/文案专家指南/skill.md`
  - 用途：获取文案赛道策略、爆款公式及违禁词规避规则。
  - 调用时机：在【核心交互流程】的【第一阶段：文案确认阶段】中调用。
