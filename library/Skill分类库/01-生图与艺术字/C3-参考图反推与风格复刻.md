# Skill C3 · 参考图反推与风格复刻

> 与 C1 的关系：C1 从「产品/品牌」推导视觉；C3 从「参考图」提取视觉。
> 两者产出都汇入 Brand Kit / 视觉方向提案，由 H1 确认。

## 一、反推指令库（按图片类型路由）

| 类型 | 反推要素 |
|------|---------|
| **通用（万能）** | 风格、人物妆容、服饰、构图、视角、元素、内容、文字 → 整理成一段连贯可直接生图的中文提示词 |
| **结构化（JSON）** | 以 JSON 结构化数据提取视觉风格——字段化输出，适合程序化复用与局部替换 |
| 字体/LOGO | 字形特征、笔画质感、衬线/倒角、立体/光泽/金属/磨砂/玻璃质感、配色、特效（描边/发光/渐变/浮雕） |
| 风景/场景 | 环境、天气、时段、光线、色调、天空云层、植被水体、透视、景深 |
| 摄影 | 相机参数、镜头焦距、光线类型（自然/硬/柔/逆光）、景深、色调（胶片/冷暖）、摄影师风格、噪点锐度 |
| 插画 | 手绘/板绘、平涂/厚涂、流派（二次元/治愈/国风）、线条粗细、肌理、画师风格 |
| 3D 渲染 | 渲染器特征（C4D/Blender/Octane）、材质（黏土/磨砂/金属/玻璃/亚克力）、三点布光、体积光、PBR |
| IP 角色/潮玩 | 头身比、五官表情、服饰配色、材质（哑光/树脂/PVC）、盲盒风格、姿态神态 |
| 视频 | 镜头语言（推拉摇移）、运动节奏、转场逻辑、景深变化、色彩分级、动态元素（光斑/粒子/布料） |

**编排层路由**：先判断参考图类型 → 选对应反推指令；程序化场景优先 JSON 结构化反推
（字段可单独替换，配合下面的「模块化混搭」）。

## 二、复刻红线（合规硬约束，写进每条提示词）

- **只学**：设计风格、排版逻辑、色调氛围、构图方式、电商设计节奏
- **禁抄**：参考图中任何原始文字/标题/卖点文案/品牌标语/装饰文字
- **禁复刻人物**：模特长相、五官、脸型、发型不得描述或复刻；国内物料负面词加"不要指定人物族裔"
- 统一负面词清单：乱码文字 / 错误品牌名 / 产品变形拉伸 / 多余零件 / 虚构结构 /
  LOGO 位移 / 廉价塑料感 / 过曝反光 / 畸形手指 / 风格割裂

## 三、实操工序（找参考 → 反推 → 混搭 → 抽卡）

**1. 找参考的三个合格标准**（不合格的参考图直接换）：
- 场景与动作契合需求（要什么场景就找什么场景）
- 核心产品足够突出
- 构图饱满、风格可与整套页面统一、模特情绪到位动作自然

**2. 反推**：参考图 + 对应类型反推指令 → 得到完整风格提示词。

**3. 模块化混搭**（关键技巧）：对反推结果不满意的模块，
找第二张参考图单独反推该模块（如服装穿搭），**只保留该模块的提示词替换进主提示词**——
色调、服装、动作、场景可各来自不同参考。

**4. 抽卡筛选**：同一提示词多次生成 → 保留候选 → 逐张放进整套版面试 → 定稿。
（工作台内对应：② 批量生成 → H1/H2 人工筛选）

## 四、电商复刻配方（与识别报告配合使用）

| 配方 | 屏数与比例 | 备注 |
|------|-----------|------|
| 跨境主图复刻 | 6 张 3:4 单图 | 多参考图（图一~图六）+ 产品图，配合 Skill 04 识别报告 |
| 跨境 A+ 复刻 | 6 屏 21:9 横屏 → 上下拼接 21:54 长图 | 输出前注明拼接关系 |
| 国内详情页复刻 | 10 屏 2:3 竖屏 | 配合 Skill 03 诊断报告；负面词禁指定族裔 |

共同结构：参考图风格复刻声明 + 识别报告卖点注入 + 产品保真硬约束
（"严格还原产品造型/包装/颜色/LOGO 位置/材质/结构比例，尺寸 1:1 不变形不增减零件"）
+ 每屏中文提示词 + 负面提示词 + 比例标注。

## 五、常用修图指令库（生成后处理，⑧ 质检打回时常用）

| 指令 | 用途 |
|------|------|
| 风格迁移 | 产品放入新场景：保造型、重置光影、色温饱和度随环境、消除接缝 |
| 产品融合 | 产品精准放入模特手中/场景：修正透视比例遮挡、加接触阴影与环境反射 |
| 移除万物 | 移除元素及其阴影反光，原位按环境自然填补，其余画面 100% 不变 |
| 产品精修 | 纯白底、还原材质（玻璃通透/塑料哑光/金属光泽）、去指纹灰尘、电商主图标准 |
| 科技特效 | 局部外壳透明化露出内部结构、加特效（爆炸图/剖视风） |
| 超高清增强 | 严格保留人物特征不变，仅提升清晰度/纹理/光影至 4K 电影级（修复 AI 图变糊） |
