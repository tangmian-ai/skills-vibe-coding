# Skill 07 · 线下印刷物料

## 交付规格（与线上组图完全不同）
- **默认 1 张高冲击主视觉**（易拉宝 80×200 思维），不是 6 张翻页组图
- 线下第一要务：**远距吸睛** > 信息密度

## 设计差异（为什么比社媒更吸睛）
| 维度 | 社媒图文 | 线下物料 |
|------|---------|---------|
| 观看距离 | 手机 30cm | **1–5 米**（路过扫一眼） |
| 停留时间 | 可翻页 3–10 秒 | **< 2 秒** |
| 创意目标 | 叙事、种草 | **停步、进店、扫码** |
| 字号 | 适中层级 | **超大主标题**（3m 可读） |
| 对比度 | 柔和原生 | **高对比、强色块** |
| 信息密度 | 可多层 | **少字、一个钩子** |

## 印刷硬规范（线上规则不适用）
- **色彩模式 CMYK**（屏幕 RGB 直接印会偏色，品牌色需备 CMYK 对照值）
- **出血 3mm**、裁切线、安全边距 5mm 内不放文字
- 分辨率 **300dpi**（大幅面广告 100~150dpi 可接受）
- 大面积深色底注意总墨量 ≤ 300%

## 物料尺寸库
| 物料 | 常规尺寸 | 要点 |
|------|---------|------|
| 门店海报 | A2 / A1 | 3 米可读：主标题 ≥ 60pt 起 |
| 易拉宝 | 80×200cm | 核心信息放**上 2/3**（下 1/3 常被遮挡）；底部留支架区 |
| 传单 DM | A5 / 三折页 | 正面 3 秒钩子，背面信息全量；折线处不压关键文字 |
| 桌卡/台卡 | A6 / 定制 | 双面利用；扫码动作引导明确 |
| 灯箱片 | 定制 | 透光材质色彩需加饱和补偿 |
| 包装贴纸 | 定制 | 刀版线内缩，圆角安全距 |

## 观看距离决定字号
`可读字高(cm) ≈ 观看距离(m) × 0.7`——门店 3 米外主标题字高 ≥ 2cm

## 生图策略
- Prompt 直接要求**高冲击带字终稿**（戏剧光影、大色块、产品 Hero 居中、主标题 3 米外可读）
- 文案来自 H0 确认稿；OCR 不过则打回重生，印刷前再核对 CMYK/出血/可读距离

## 二维码规范
- 最小印刷尺寸 2×2cm；深底用反白码需测试扫码率
- 传单/海报必须有"扫码动作引导语"（扫码领 X）

## 强制核对（H0 节点）
- 门店地址/营业时间/POI、价格、印厂色样确认（打样环节人工）
