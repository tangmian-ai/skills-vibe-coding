# 爆款生成公式

### 第二部分：小红书人像封面爆款生成公式

**核心作用说明**：
在消化了 **references/设计原则与标准.md** 中的设计原则后，Agent 应已具备专业的设计认知。本章节将这些通用的设计原则具体化、工具化，针对 **小红书人像封面** 这一特定场景，提供了一套经过验证的**爆款 Prompt 填充逻辑**。本部分内容与 **skill.md** 中的 **1. Prompt 生成核心结构** 中的各个维度一一对应，为 Agent 提供了每个字段（如人物、背景、排版、字体、配色、装饰）在小红书语境下的**最佳实践范本**。请调用此处的具体策略来填充 Prompt 结构，确保生成的封面具备“高点击率”基因。

#### 1. 海报主题
- **核心要求**：根据用户输入的主题或文案，进行超精简概括，提炼出海报的核心主题。
- **字数限制**：**严禁超过 10 个字**。
- **作用**：确保 Prompt 的 `[海报主题]` 字段聚焦、精准，引导模型生成符合主题的画面氛围。

#### 2. 人物维度
- **核心要素**：包含 **性别、着装、表情、手部动作细节/腿部动作、景别、拍摄角度** 六大维度。
- **生成逻辑**：必须严格依据 **skill.md** 中的 **3. 用户创作场景触发与执行逻辑** 动态调整：
  - **🎨 同款封面复刻 (模式 A)**：**基于参考图 + 按需响应指令**。默认保持参考图1人物形象，着装，表情，动作，若用户有明确修改指令（如“改动作，与图2保持一致”），则优先执行指令。
    > **输出示例**：
    > `[人物维度]`：参考图1的人物形象，服装，表情，动作，修改动作为：双手比耶，面带微笑。（注：若无修改指令，则只输出“严格参考图1的形象，表情，动作”）
  - **✍️ 博主风封面定制 (模式 B)**：**基于参考图 + 绝对保持动作/表情**。严禁脑补不存在的动作或视线，确保与原图一致。
  - **💬 虚拟IP封面定制 (模式 C)**：**基于规则生成**。
    - 若指定虚拟形象：调用 **references/行业人像特征/references/虚拟角色.md**。
    - 若指定真实人像：调用 **references/行业人像特征/skill.md** 中的赛道规则。
    - 若无明确要求：默认生成虚拟卡通形象。
- **生成要点**：
  - **人物描边**：为人物添加描边样式（如白色粗描边、虚线描边、半包围白色粗描边），使人物与背景分离，增强视觉聚焦与海报感。
- **肤质描述 [必填]**：根据人物性别/年龄，**必须**在 Prompt 的 `[人物维度]` 字段末尾添加以下对应描述：
  - **女性**：`美白，均匀肤色提亮肤色，肤质哑光细腻，轻透裸肌感，真实毛孔纹理`。
  - **男性**：`肤质哑光细腻，轻透裸肌感，真实毛孔纹理`。
  - **儿童**：`均匀肤色，匀净哑光质感`。
#### 3. 背景维度
- **品质标准**：**【优先参考】** 参见 **references/设计原则与标准.md** 中的 **1. 小红书物料品质标准 - 背景** 相关内容。
- **生成逻辑**：与 **主题/文案/用户输入背景描述** 强相关，确保背景能烘托核心内容。
- **生成要点**：
  - **实景为主**：选择近景局部，不杂乱、有真实感（避免大广角、样板房）。
  - **虚化处理 (最高优先级)**：场景必须进行虚化处理以突出人物，增强松弛的氛围感（除非用户明确指定清晰背景）。
  - **纯色背景**：如使用纯色，色彩偏向中性调，避免喧宾夺主。

#### 4. 装饰元素
- **品质标准**：**【优先参考】** 参见 **references/设计原则与标准.md** 中的 **1. 小红书物料品质标准 - 图形/图像** 相关内容。
- **生成逻辑**：与 **主题/文案/用户输入装饰元素描述/人物情绪** 强相关。若无法找到强相关的元素，则**不生成任何装饰**，宁缺毋滥。
- **生成要点**：
  1.  **网感Emoji为主**：列举所有装饰元素，优先使用高网感的Emoji图标。
  2.  **极小尺寸与低层级**：在Prompt中必须注明“极小尺寸”，明确其为**辅助作用**，视觉层级最低，严禁喧宾夺主。
  3.  **数量限制**：装饰元素数量**严禁超过 3 个**。
  4.  **功能性辅助**：图标需起到说明内容属性的作用（如📚表示学习/教育，💡表示要点/亮点）。

#### 5. 文案信息
- **生成逻辑**：严格按照用户提供的文案进行填充，**绝对忠实**于用户的原文。
- **生成要点**：
  1.  **严禁脑补**：**严禁**自己添加任何文案。
  2.  **按需生成**：如果用户**没有提供**辅助文案，则**不要生成**任何关于辅助文案的相关信息，删除对应字段。

#### 6. 版式框架
- **生成逻辑**：依据 **skill.md** 中的 **3. 用户创作场景触发与执行逻辑** 动态调整：
  - **🎨 同款封面复刻 (模式 A)**：**基于参考图 + 按需响应指令**。默认照搬参考图2的结构布局；若用户有明确修改指令（如“文字改到左边”），则优先执行指令。
    > **输出示例**：
    > `[版式框架]`：严格参考图2的版式框架。（注：若无修改指令，则直接输出此内容；若有指令则输出：严格参考图2的版式框架，修改：文字改到左边）
  - **✍️ 博主风封面定制 (模式 B) / 💬 虚拟IP封面定制 (模式 C)**：**基于规则生成**。综合参考 **references/设计原则与标准.md** 中的 **1. 小红书物料品质标准 - 排版** 相关内容及下方的四大爆款构图。
- **四大爆款构图**：
  - **🎯 三分构图 (默认首选)**：画面垂直三等分，最上方放标题、中间放人物（+辅助文案/装饰）、最下方放副标题。结构清晰，视觉稳定。（若用户无特殊要求，**默认使用此构图**）。
  - **💥 包围构图**：用大字号文字把图片包围起来（通常在四角），视觉冲击力强。
  - **✨ 叠压构图**：文字和人物部分产生叠压关系，营造层次感。
  - **👀 C字构图**：文字沿着图片边缘呈 C 型分布，引导视线聚焦主体。
- **填充示例 (以三分构图为例)**：
  `[版式框架]：[顶部区域：主标题一字排开]，[中部区域:人物放置在画面中心，辅助文案分别放在了人物左右两边],[底部区域：副标题“xxx”“xxx”分段在画面底部展示]`。



#### 7. 字体样式
- **生成逻辑**：依据 **skill.md** 中的 **3. 用户创作场景触发与执行逻辑** 动态调整：
  - **🎨 同款封面复刻 (模式 A)**：**基于参考图 + 内容替换**。
    > **识别与替换逻辑**：Agent 必须先识别参考图2中的文字层级（主标题/副标题/辅助文案），然后将确认后的文案进行一一对应替换。
    > **输出示例**：
    > `[字体样式]`：参考图2的字体样式，将主标题【万赞封面（原参考图文案）】改为【运营干货（用户确认文案）】，将副标题【一分钟GET，新手友好（原参考图文案）】改为【零基础入门，轻松上手（用户确认文案）】。（注：若参考图无副标题或辅助文案，则不输出对应替换指令）
  - **✍️ 博主风封面定制 (模式 B) / 💬 虚拟IP封面定制 (模式 C)**：**基于规则生成**。综合参考 **references/设计原则与标准.md** 中的 **1. 小红书物料品质标准 - 文字** 部分及 **2.2 字体选用原则**。
- **生成要点 (仅适用于模式 B 和 模式 C)**：
  - **文字效果**：可适当添加粗糙化、笔触纹理、变形等效果，拒绝立体的复杂效果。
  - **主标题**：大字主导，建立强烈的信息层级。
  - **副标题**：画面关系弱于主标题。字多时（分段呈现），字少时（一字排开），采用醒目颜色和图标引导视线。
- **精准高亮策略 (仅适用于模式 B 和 模式 C)**：
  - **严禁抽象指令**：严禁写“基于词义高亮”！Agent 必须先分析主标题，提取 1 个核心诱饵词（如“起号”、“避坑”、“月入过万”）。
  - **像素级描述**：将主标题拆分为两部分描述。例如：“常规文字【自媒体怎么】为黄色中大字号；核心关键词【起号】为蓝色超大字号”。
  - **严禁重复输出**：拆分描述后的文字组合起来必须与原文完全一致，**严禁**重复输出文字或遗漏文字。
    > **输出示例**：
    > `[文案信息]`：[主标题：宿舍好物挖到宝了]
    > `[字体样式]`：[主标题：“宿舍好物”，圆润可爱字体，明黄色，“挖到宝了”为橙色超大字号，加红色手绘圈强调]
- **重点强调 (仅适用于模式 B 和 模式 C)**：
  - **划重点**：在主标题末尾添加强调效果，形式包括：划圈、加粗下划线，针对核心诱饵词进行视觉增强。

- **配色要点 (为字体样式服务)**：
  - **色彩策略**：均遵循「主色60%+辅色30%+点缀色10%」黄金配比。
  - **色彩统一性**：画面所有元素（文字、背景、装饰）均需遵循「中等饱和度+中等明度」核心要求。
  - **强对比**：颜色需和背景能区分开，色彩对比强烈，确保手机小屏幕清晰可读。
  - **撞色设计**：主标题可灵活采用对应赛道适配的撞色思路。
  - **限制数量**：主副标不超过 3 个颜色，避免视觉杂乱。



#### 8. 图层前后关系
- **生成逻辑**：明确画面排列顺序，确保视觉层级分明。
  - **🎨 同款封面复刻 (模式 A)**：**基于参考图**。
    > **输出示例**：
    > `[图层前后关系]`：参考图2
  - **✍️ 博主风封面定制 (模式 B) / 💬 虚拟IP封面定制 (模式 C)**：**基于规则生成**。
- **生成要点 (仅适用于模式 B 和 模式 C)**：
  - **参考原则**：遵循 **references/设计原则与标准.md** 中的 **层次分明**、**焦点强调**、**留白得当** 原则。
  - **默认顺序(三分构图)**：**装饰元素 (最上层) > 辅助文案 > 副标题 >人物 > 主标题 > 背景 (最底层)**。确保文字不遮挡人物面部，装饰元素不干扰核心信息。

#### 9. 画面比例
- **固定输出**：3:4。
