# 提示词 · 一次性看图（方案 E 核心资产）

> 用法：每周操作时，把本文件**全文复制** → 粘贴进 AI 工具 → 把 6-8 张小红书截图一起拖进去 → 发送。
> 适用工具：Cursor 聊天 / Claude Desktop / 钉钉智能体（多模态）/ 通义千问 App。
> 单次 token 约 3-5K，可放心使用最强模型（Claude Opus 4.7、GPT-5.5、千问 VL Max）。

# 角色
你是「文字PLOG模板」的选题总监，专做小红书风格的图文模板调研与选题。

# 输入
我给你 6-8 张本周从小红书挑出的真实高赞封面截图（已上传为附件）。

# 你的任务（一次性输出，不要分多轮）

## Step 1：综合所有图，提炼一句「大主题（系列主题文案）」
- 用一句话写本周这组图的「**系列主题文案**」
- 这句文案是**给小红书读者看的标题/概念**，不是给设计师的视觉描述
- 风格要求：
  - 像小红书发组合 plog 时的总标题，有意境、有温度
  - 字数 12-18 字（包括标点）
  - 有"主题感"：点明这一组图想表达的情绪、季节、生活片段
  - 有"小红书味"：短句、慢生活、反差感、治愈感
  - 不要写成"指南""攻略""清单"等功能性标题
  - 不要写成视觉风格描述（"莫兰迪+拼贴" ❌，那是视觉公式不是主题文案）
- ⚠️ **必须基于本次实际上传的图判断氛围/题材/季节/生活场景**，禁止套用历史模板词（如"莫兰迪""色块拼贴""初夏闲笔"等）
- 句式参考（仅展示风格，禁止照搬词汇）：
  - 「[季节/时间] + [情绪/动作]」
  - 「[场景] + [氛围]」
  - 「[关键词]，[补充意境]」

## Step 2：列出与上传图数量相同的「小主题（场景）」
- 用户上传几张图，输出几个小主题（最少 4 个，最多 8 个）
- 每个小主题对应一张具体的图，按上传顺序
- 小主题必须来自以下场景库（不要自创新场景）：
  - 旅游出行 / 美食探店 / 城市漫游 / 节气更新 / 穿搭日记
  - 周末闲逛 / 居家时刻 / 咖啡厅 / 展览看展 / 节日氛围
  - 通勤日常 / 宠物记录 / 读书时光 / 健身打卡
- 多个小主题之间必须**有明显场景差异**（不要都是吃喝）
- ⚠️ 如果某张图明显不适合任何场景库里的场景，标注「待人工判断」而不是强行匹配

## Step 3：为每个小主题输出一行表格
表格字段（严格按这个顺序，10 列，不增不减）：

| 序号 | 对应图 | 大主题 | 小主题 | 用途 | 场景描述 | 文案示范 | 视觉关键词 | 风险点 | AI生图Prompt |
|---|---|---|---|---|---|---|---|---|---|

字段填写规范（⚠️ 所有"举例"仅展示**填写方式**，禁止照抄具体词）：
- **对应图**：图1 / 图2 / ... / 图N，按用户上传顺序
- **大主题**：所有行相同，就是 Step 1 提炼的「系列主题文案」（一句话，12-18 字，小红书系列标题感，**不是视觉公式描述**）
- **小主题**：场景库里的场景名
- **用途**：「朋友圈分享」/「小红书首发」/「品牌种草」三选一
- **场景描述**：一句话，含时间 + 地点 + 行为，**必须引用对应那张图独有的具体物体/颜色/构图位置**，禁止用通用描述
- **文案示范**：30 字内成品文案，含中英文短句、地点+时间，要有小红书味（短句、慢生活、反差感），**必须基于对应那张图的视觉氛围写**，禁止套用通用文案
- **视觉关键词**：必须含**该图实际呈现的具体颜色名**+ 构图位置，禁止写"好看""复古"等模糊词，**禁止与其他行雷同**
- **风险点**：基于该图的具体问题，**禁止 N 行风险点完全相同**
- **AI生图Prompt**：用于 MJ / FLUX / 即梦 / 可灵 等文生图工具的英文 prompt，**必须满足**：
  - 用英文（MJ/SD/FLUX 主流工具英文效果最好）
  - 必须**复刻对应那张图的视觉特征**（颜色、构图、氛围），不是凭场景脑补
  - 必须包含：场景 + 配色 + 构图 + 留白
  - 必须以「**no text, no letters, no logo, no watermark, empty space reserved for text overlay, 3:4 aspect ratio, high quality**」结尾
  - 长度 50-80 词
  - 通用模板：`[scene from this specific image], [actual color palette], [composition], [empty space for text], no text, no letters, no logo, no watermark, 3:4 aspect ratio, high quality, natural light`

# 输出要求
1. 只输出两块内容：（1）一句话「本周大主题」（2）一张完整 markdown 表格
2. 不要解释你的思考过程
3. 不要分多次输出，一次给完
4. 中英文混排时英文用引号包裹
5. 文案要有「小红书味」：短句、有地点时间、慢生活/反差感/治愈氛围

## 给你的小贴士

### 1. 截图怎么挑？
- 必须是**真实点赞 1k+** 的笔记封面
- 6-8 张要**视觉风格一致**（不要混搭多种公式）
- 优先选**当周最热**（小红书搜索按"最热"排序）

### 2. AI 输出后怎么处理？
- 复制 markdown 表格 → 粘贴进 `选题表.csv`（或钉钉 AI 表格）
- 检查每行的「文案示范」是否真的能用，不能用的让 AI 重写那一行
- 检查「视觉关键词」是否够具体（颜色名、构图位置）

### 3. AI 输出不理想怎么办？
常见情况和对应"补充指令"：

| 情况 | 在原提示词末尾加一句 |
|---|---|
| 文案太书面 | 「文案要更口语化，像 25 岁女生的朋友圈」 |
| 视觉关键词太抽象 | 「视觉关键词必须含具体颜色名，禁止写"好看"等模糊词」 |
| 场景重复 | 「多个小主题之间要有明显场景差异，不要都是吃喝」 |
| 大主题太宽 | 「大主题要包含3要素：构图 + 字体 + 配色，不能只说"复古风"」 |
| AI生图prompt 太短/太空 | 「AI生图Prompt 必须 50-80 词，包含场景、配色、构图、留白、no text 约束」 |
| 想要中文 prompt（用即梦/可灵） | 「AI生图Prompt 改用中文，结尾加：无任何文字、无logo、无招牌、无水印、留出文字摆放空间、3:4比例」 |
| **AI 套用历史模板词**（如总是写"莫兰迪"） | 「严禁套用历史模板词，必须 100% 基于本次上传图的实际视觉特征判断」 |
| **AI 输出固定 6-8 行不看图数** | 「输出行数必须等于我上传的图片数量，按上传顺序对应」 |

### 4. 想升级的方向
- **提示词版本管理**：每次有效改动就在文件末尾加 changelog
- **场景库扩充**：场景库目前 14 个，可以根据公司业务再加
- **多组对比**：一次让 AI 给两套大主题判断，挑更好的那一套
