# Skill 06 · 私域/微信生态

## 关键差异：二维码是合法元素
公域（小红书等）二维码是引流红线；**私域海报二维码是核心转化组件**——
但要遵守微信诱导分享规则（禁"不转不是中国人"式强制话术）。

## 物料清单
| 物料 | 尺寸 | 要点 |
|------|------|------|
| 朋友圈海报 | 3:4 / 1:1 | 缩略图可读：主标题在上 1/2，二维码右下角 ≥ 180px |
| 公众号封面对 | **21:9（900×383）+ 1:1** | 一稿两裁：主视觉焦点放 21:9 与 1:1 的交集安全区 |
| 社群裂变海报 | 9:16 | 固定占位：用户头像+昵称区（顶部）、二维码区（底部）、利益点（中部） |
| 小程序 banner | 750×300 等 | 点击热区留白，文案 ≤12 字 |
| 企微欢迎语配图 | 1:1 | 品牌感 + 服务清单 |

## 裂变海报公式
`身份认同标题 + 3 条利益点 + 价格锚点（划线价）+ 限时/限量 + 二维码 + 长按提示`
- 合规：奖励规则写清、禁虚构"已有 N 人参加"、活动解释权声明

## 版式
- 朋友圈信息流缩略场景：主标题字号 ≥ 短边 8%，弱光环境可读
- 公众号封面对：文字只放交集安全区，避免 1:1 裁切丢字

## 强制核对（H0 节点）
- 二维码有效性与落地（活码/群码上限）、活动规则、价格
