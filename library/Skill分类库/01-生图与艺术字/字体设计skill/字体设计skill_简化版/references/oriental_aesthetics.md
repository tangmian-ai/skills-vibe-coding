# 东方美学 (Oriental Aesthetics)

适用：书法、篆刻、民俗、国潮、传统节日

## 风格词库
- **书法与手写**：中式楷体、小楷、行书体、草书、狂草、书法手写
- **古韵与篆刻**：篆书字体、隶书、秦篆、复古复刻、印章风格
- **国潮与非遗**：中式剪纸、云纹字、版画元素、解构主义书法、机械宋体

## 视觉要求
- **字形**：用 [舞动丝带]、[行云流水]、[一气呵成] 描述笔势；用 [错位]、[夸张]、[挤压] 描述结构变形
- **材质（按语境选用）**：
  - 节庆喜庆语境（新春/福/大吉等）→ [烫金]、[浮雕金漆]、[红底金字]、[漆面光泽]、[崭新饱满]，严禁破损/斑驳/风化
  - 书法水墨语境 → [墨色晕染]、[飞白枯笔]、[印泥质感]
  - 篆刻印章语境（印章/图章/篆刻/篆书）→ **字形必须为篆书**（笔画圆润均匀粗细一致、结构对称古朴，严禁用楷体/宋体/黑体替代）；方形构图1:1；四字→2×2方阵排列；外围方形印章边框线；阳刻（白底朱红字）或阴刻（红底白字/金字）按用户指定；**印章作为画面中的构图元素居中呈现，占画面约30%-50%，四周保留充足留白，严禁撑满画面**
  - 古韵历史语境（用户明确要求古旧/做旧时）→ [石刻崩缺]、[斑驳岁月痕迹]
- **版式**：书法类保持大面积留白，突出笔墨张力
- **背景收敛**：墨色晕染/飞白飞溅效果必须收敛在文字笔画边缘，严禁扩散到背景区域
- **反悖论**：严禁金属、霓虹、塑料等现代工业材质（国潮混搭除外）；节庆语境允许金色/烫金

## 示例
- 书法飞白：`"晚霞与玫瑰共绘浪漫"，采用书法艺术字设计，运用飞白枯笔技法，横竖笔画刻意错位制造动态。字体边缘有水墨晕染效果。纯白色背景。`
- 新春浮雕：`3D艺术字体设计，四个字"新春大吉"，立体浮雕风格（字形饱满厚重，笔画边缘带有精致的回纹装饰线），烫金材质（表面光滑崭新，带有金属高光反射），纯红色背景。比例4:3`
- 剪纸非遗：`红色文字"新年快乐"，中国风非遗创意字体设计，以复杂的剪纸图案组合拼接形成（图案内容包括植物、动物、传统纹样等），纯白色背景。`
- 篆刻印章：`干净的纯红色背景。平面艺术字体设计，四个字"馬年大吉"，篆书字形（笔画圆润均匀粗细一致，结构对称古朴厚重），2×2方阵排列，外围方形印章边框线，烫金色字体，印章居中占画面约40%面积，四周大量留白。比例1:1`
