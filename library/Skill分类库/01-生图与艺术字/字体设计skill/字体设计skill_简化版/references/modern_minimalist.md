# 现代极简 (Modern Minimalist)

适用：科技、时尚、商务、文艺、简约现代

## 风格词库
- **常规与极简**：无衬线字体、宋体、圆角字、纤细黑体变体、几何化处理、抽象变形
- **连笔与手写**：简约连笔、童趣手绘式笔画、超细手写体、极细无衬线风格手写字体
- **时尚与优雅**：欧美风扁平化、女性优雅风格、曲线设计感

## 视觉要求
- **字形**：用 [几何切割]、[积木堆叠]、[线条重构]、[圆润] 描述；必须有可见设计痕迹（笔画断开/连接/错位/极简线条组合）
- **色彩**：[单色] 或 [类比色]，避免高饱和杂色，追求纯粹
- **反悖论**：严禁锈迹、破损、水墨等复古或自然材质

## 示例
- 极简非衬线：`白色字"有点意市"，时尚简约的抽象字体，采用极简的线条组合（将文字笔画简化为流畅的几何形状，粗细对比强烈）。纯黑色背景。`
- 扁平连笔：`"cake"，欧美风扁平化连笔设计风格，艺术化、流畅且富有装饰性的字母，线条纤细流畅，纯白色背景。`
- 哥特花体：`中文内容"爱如星辰"，采用艺术化哥特风格字体设计，笔画形态尖锐转灵动（笔画如丝带般飘逸缠绕，有粗细对比强烈的特点），黑色主体。纯白色背景。`
- 综艺动感：`白字"秋风伴暖阳，露营正当时"，漫画式综艺字体，字形结构（结构宽松，夸张、富有张力的不规则结构，部分笔画有明显的伸展和变形，部分笔画相互穿插、避让）。纯黑色背景。`
