# 设计原则与标准

### 第一部分：小红书物料品质标准和设计原则

**核心作用说明**：
本章节旨在赋予 Agent **专业设计师的审美视角与判断力**。Agent 需将以下设计原则内化为画面生成的**底层逻辑**，在构建 Prompt 时，不只是简单地堆砌元素，而是从**构图平衡、视觉层级、色彩心理、光影逻辑**等专业维度进行思考。确保最终产出的封面不仅符合小红书平台的画质规范，更具备引发用户点击的视觉张力与美学质感。

#### ⚠️ Skill 生成全局规则：画面比例
- **固定比例**：所有输出的图片必须严格遵循 **3:4** 的纵横比（Aspect Ratio），这是小红书笔记在移动端展示的最佳比例，确保内容不被裁切，且占据最大屏幕空间。

#### 1. 小红书物料品质标准
> **说明**：本部分定义了小红书爆款封面必须达到的**结果性指标**。Agent 在生成 Prompt 时，需以此为验收标准。若对其中的设计术语或实现方法（如“如何实现对齐”、“如何构建对比”）存在疑问，请查阅下方的 **2. 设计原则** 章节获取具体的方法论支持。

##### 1. 和谐统一
- **文字**：
  - 选择与主题和风格相匹配的字体来传达情感或强化信息。
  - 保证字体间搭配的统一性（通常：黑体配无衬线、宋体配衬线、圆体配圆体）。
  - 考虑受众的语言和文化背景，使用相匹配的主题文案，避免引起误解。
- **图形/图像**：
  - 选择合适的图像，能够直观地传达海报主题，图形和样式需要适应设计需求。
  - 通过统一的图像处理（调色、剪裁、合成等）来保证整体设计的一致。
  - 注意图像间的大小比例保持平衡，与真实情况保持一致（风格化另议，如超现实）。
  - 描边类型的图像保持粗细视觉上统一（风格化另议）。
- **色彩**：
  - 与主题或行业特性相匹配，能够更好的强化信息和情感表达。
  - 使用色彩搭配工具或理论来搭配颜色，使视觉平衡舒适，避免过于刺眼或不协调（脏乱、陈旧）的配色。
  - 通过理解色彩心理学的代表含义，明确主题的情绪氛围，与主题保持统一。
- **排版**：
  - 使用版式重复原则来保证画面的整齐统一，可以是形式、字号、色彩、对齐方式的统一。
  - 合理布局图文信息，考虑各元素之间的间距和比例，确保整体的视觉平衡感。
- **光影**：
  - 确定主光源的位置，统一画面各元素的光源方向。

##### 2. 层次分明
- **文字**：
  - 通过**字号、字重、字色、投影、字效、添加图形**等来区分标题、副标题和正文等信息的层级结构。
- **图形/图像**：
  - 使用**大小、颜色、位置、层级、虚实**来梳理图形的层次。
- **色彩**：
  - 通过颜色的**深浅或冷暖**来创建视觉层次，更好的引导观众的视线和注意力。
- **排版**：
  - 使用版式**亲密性原则**来梳理层级关系，并用**对比原则**来区分整体画面的层次。
  - 把文本与符合主题调性的**符号/色块/线条/文本背景**做结合，增加画面层次。
  - 结合**点线面**的处理，进行**动线引导**。

##### 3. 焦点强调
- **文字**：
  - 通过**颜色、材质、字号、字重、字效、添加图形**等方式来强调核心文案信息。
- **图形/图像**：
  - 可通过醒目的**图形、大胆的图像**作为视觉焦点，作为吸引观众注意力的核心区域。
- **色彩**：
  - 使用**强烈的对比配色**技法，来突出关键要传达的信息或视觉元素。
- **排版**：
  - 通过**强对比的排版原则**来强调焦点。

##### 4. 传达清晰
- **文字**：
  - 选择**易读**的字体。
  - 调整**字号字重，间距**，确保在不同的尺寸和距离下都能清晰阅读。
  - 通过**字色、字效、投影或立体效果**来增加文字与背景的对比。
- **图形/图像**：
  - 保证图像的**合理性**，符合认知。
  - 图形图片的**主体完整无残缺**，整体造型结构协调。
  - 使用**高质量、清晰度高**的图片。
- **背景**：
  - 避免使用**过度复杂/杂乱**的图像，以免分散观众的注意力。
  - 注意**对比**，不影响前景文本或图像的识别。
- **光影**：
  - 遵循“**近亮远暗**”原则，画面光影符合常理，即物体距离离光源越近的部分越亮，越远的部分越暗。

##### 5. 留白得当
- **文字**：
  - 注意文字与文字层级间的**空间留白**，保持画面的**呼吸感**。
- **图形/图像**：
  - 涉及图形和图像结合，需注意**保留空间**，避免图像看起来被挤压或剪裁不当。
- **排版**：
  - 需考虑需求调性，利用**版面率知识**，创造出相匹配的画面气质。
  - **高版面率**-留白少，画面气质更活泼、热闹。
  - **低版面率**-留白多，画面气质更典雅、安静。


##### 6. 细节丰富
- **文字**：
  - 使用**填充（颜色/图案）、描边、错落、变形、材质**等方式来丰富字体效果。
- **排版**：
  - 通过给文本添加**点线面、色块、图形、符号**等元素来丰富细节。
  - 巧用**相似或反差字体**进行搭配，使版式得到优化。
  - 正文段落类型，需注意：**标点符号避头尾、单字不成行、字距行距、段首缩进**（非文章排版）等要点。

#### 2. 设计原则
> **说明**：本部分是达成上述品质标准的**过程性方法论**。作为 Agent 的“设计知识库”，当需要实现具体的视觉效果（如“增强层次感”、“优化排版”、“选择合适字体”、“确定人像风格”）时，请调用此处的**版式四大原则**（对齐、对比、亲密、重复）、**字体选用原则**（受众、行业属性）以及 **references/行业人像特征/skill.md** 来指导 Prompt 的细节构建。

#### 2.1 版式四大原则

##### 1. 对齐
- **左对齐**：阅读效率最高的一种排版。
- **居中对齐**：多用于居中对称的版式，常用于标题导语和短片文字排版中。
- **右对齐**：只适用于少量文字。
- **两端对齐 末行左对齐**：最常用的段落性文字编排形式，多用于杂志、画册、报纸的编排。
- **两端对齐**：可以使画面充满严谨与秩序感。
- **顶对齐**：可以营造出复古的文化氛围。
- **底对齐**：一般作为装饰性文字展示。
- **版式文字基本原则-对齐**：
  1. 把画面所有的文字和元素进行对齐，让画面充满视觉关联与整洁感。
  2. 常用的对齐方式有左对齐、右对齐、居中对齐。
  3. 其中左对齐是阅读效率最高也是应用最多的对齐方式。

##### 2. 对比
- **大小**：突出文字内容的主次。
- **粗细**：粗的字体显重，细的字体显轻，形成轻重对比，影响视觉中心。
- **色彩**：区分信息，装饰画面。
- **字形**：衬线字体和非衬线字体，和各类字体设计，让画面更加丰富多样。
- **方向**：增加版面的动感或者空间感。
- **疏密**：密集排版形状块装，视觉上更加紧凑；疏的排版可以展示画面的主题。
- **肌理**：通过对字体赋予不同的肌理来展示不同的视觉感受。
- **动静**：动使整个版面充满活力；静可以使整个版面有稳定的效果。
- **空间**：通过近大远小，近实远虚等表现形式，能营造很好的空间层次和氛围感。
- **版式基本原则-对比**：
  1. 通过元素间的差异（大小、颜色、字体、形态等）突出视觉层次，引导用户注意力。
  2. 对画面的重要信息放大突出，次要信息弱化减小。

##### 3. 亲密
- **规律总结**：组间距 > 段间距 > 行间距 > 字间距
- **版式基本原则-亲密**：
  1. 通过调整间距，让相关的元素形成信息层级和逻辑关系，提高信息的阅读效率。
  2. 将画面中相关联的元素放在一起，无关联的区分开。
  3. 关联性越大，间距越小，反之拉大。
- **字间距**：
  1. 字间距一般默认为0，也可以调整-20至-40之间。
  2. 为了更好的视觉效果，字间距最好也不要超过字体字号的一半。
- **行间距**：
  1. 正文推荐1.5-1.8倍，标题可缩小至1.2-1.5倍。
  2. 信息多，行间适当增大，反之，信息少，行间距适当缩小。
  3. 当小于1.2倍或大于2倍则会影响到正常阅读。
- **段间距**：
  1. 段间距 ≥ 行距的 1.5倍。
- **组间距**：
  1. 取最大字体的1/2做标准或最小文字的一倍做标准。
  2. 如果组间距过于紧凑，会影响信息阅读。
- **字号推荐大小**：
  - 主标题：字号比例：2.5-3倍
  - 副标题：字号比例：1.5-2倍
  - 正文：字号比例：基准值
  - 注释：字号比例：0.8-0.9倍

##### 4. 重复
- **色彩重复**：使用重复的颜色可使版面变得和谐统一。
- **文字重复**：字体、字号、字重（粗细）、效果一致，方便阅读和信息的传达。
- **图片重复**：大小、色调、比例、裁切一致，可使画面美观、统一。
- **元素重复**：重复的元素起到了强调和装饰的功能，丰富了视觉效果，同时使画面具有统一感。
- **重复差异**：避免版式的单调与平淡，增强版面的趣味性，形成反差和区分主次。
- **版式基本原则-重复**：
  1. 通过重复使用相同元素（字体、形状、颜色等），可以让画面表现出统一性，秩序感。
  2. 重复可以增强品牌记忆，降低用户认知成本，引导用户视觉流向。
  3. 重复可以让画面富有逻辑性，更好传达信息。
  4. 重复可以让画面具有秩序化和统一感，反之，在重复性中产生变化则能强化视觉引导。

#### 2.2 字体选用原则

##### 1. 受众人群
- **男人**：表现刚硬，坚强，力量，勇敢。字形上应选用 **棱角分明、简单直接** 的字体。
- **女人**：表现柔美，细腻，婉约，温柔。字形上应选用 **字形柔美、纤细** 的字体。
- **老人**：表现岁月痕迹，文化沉淀。字形上应选用 **古朴、具有年代感** 的字体。
- **小孩**：表现天真，活泼，好动，可爱。字形上应选用 **字形圆润，灵活** 的这类字体。
- **宠物**：表现可爱、亲近、保护欲。字形上应选用 **卡通，手写** 这类比较轻松的字体。

##### 2. 行业属性
- **餐饮行业**：拉动观者的食欲，拉近与观者的距离。字形上应选用 **带有手工感** 的字体会比较合适。
- **运动行业**：表现运动时的碰撞感，动感。字形上应选用 **带有黑体字形** 的字体会比较合适。
- **旅游行业**：表现亲近自然，人文风土。字形上应选用 **手工感比较重** 的字体会比较合适。
- **母婴行业**：表现亲近安全，可靠。字形上应选用 **圆润无棱角** 的字体会比较合适。
- **时尚行业**：表现高冷，冷淡，自我随性。字形上应选用 **相对灵活常规的衬线体无衬线体** 都可能使用。
