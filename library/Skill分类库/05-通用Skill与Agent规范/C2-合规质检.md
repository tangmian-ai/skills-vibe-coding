# Skill 05 · 合规质检

## 三级判定
| 等级 | 含义 | 行为 |
|------|------|------|
| ⛔ REJECT | 强禁词/广告法违禁/平台红线 | 必改，不允许发布 |
| ⚠️ REVIEW | 有风险但可改写或加披露 | 人工复核 + 给改写建议 |
| ✅ PASS | 无明显风险 | 放行（价格/活动/POI 仍需人工核对） |

## 检查顺序
1. 绝对化用语与极限词（最/第一/顶级/100%/永久…）→ ⛔
2. 引流红线（微信号/二维码/"+v"/外链暗示）→ ⛔
3. 品类专属禁词（非特证化妆品禁"美白"、食品禁疗效、母婴禁母乳对比…）→ ⛔/⚠️
4. 数据与资质（销量/排名/专利/获奖需有据）→ ⚠️
5. 报备与利益披露（合作笔记须挂赞助标识）→ ⚠️
6. **成品图 OCR**：文字与 H0 确认稿逐字比对 + 封面文字合规扫描
7. **视觉质量（C4）**：清晰度 / 产品保真 / 风格一致性 / AI 廉价感 / 平台硬规范（Amazon 白底等）
8. 输出报告：风险项（原句→原因→改写）+ 可发版本

## 高频改写库（节选）
| 违规 | 改写 |
|------|------|
| 全网最低 | 新人价 / 月度限时价 |
| 立刻见效 | 短时间内能感受到 |
| 美白（无特证） | 提亮 / 均匀肤色 |
| 治愈/消炎 | 舒缓 / 维稳 |

## 输出模板
```text
结论：PASS / REVIEW / REJECT
风险项：1. [原句]→[原因]→[改写建议]
必须人工核对：价格 / 活动时间 / POI / 数据来源
```
