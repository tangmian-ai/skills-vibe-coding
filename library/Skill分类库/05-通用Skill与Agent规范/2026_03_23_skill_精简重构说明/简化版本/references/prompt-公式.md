# Prompt 字段填充规则

## 1. 海报主题
- 根据用户文案超精简概括，**严禁超过 10 字**

## 2. 人物维度
- **六大维度**：性别、着装、表情、手部/腿部动作、景别（全身/半身/胸像/特写）、拍摄角度
- **人物描边**：添加白色粗描边/虚线描边/半包围白色粗描边，使人物与背景分离
- **肤质 [必填]**：
  - 女性：`美白，均匀肤色提亮肤色，肤质哑光细腻，轻透裸肌感，真实毛孔纹理`
  - 男性：`肤质哑光细腻，轻透裸肌感，真实毛孔纹理`
  - 儿童：`均匀肤色，匀净哑光质感`

## 3. 背景维度
- 实景为主，选择近景局部，不杂乱、有真实感
- **虚化处理（最高优先级）**：场景必须虚化以突出人物（除非用户指定清晰背景）
- 纯色背景偏中性调，避免喧宾夺主

## 4. 装饰元素
- 优先使用高网感 Emoji 图标（如📚💡）
- 极小尺寸，辅助作用，视觉层级最低
- **数量严禁超过 3 个**，无强相关则不生成

## 5. 文案信息
- **严禁脑补**，绝对忠实用户原文
- 用户未提供辅助文案则删除对应字段

## 6. 版式框架（四大爆款构图）
- **三分构图（默认首选）**：顶部主标题 → 中部人物+辅助元素 → 底部副标题
- **包围构图**：大字号文字在四角包围图片，冲击力强
- **叠压构图**：文字与人物部分叠压，营造层次感
- **C字构图**：文字沿边缘呈 C 型分布，引导视线聚焦主体
- 示例：`[顶部：主标题一字排开],[中部：人物居中，辅助文案在左右],[底部：副标题分段展示]`

## 7. 字体样式
- **主标题**：大字主导，强信息层级；可添加粗糙化/笔触纹理效果，拒绝复杂立体效果
- **副标题**：弱于主标题，字多分段、字少一字排开，醒目颜色+图标引导
- **精准高亮策略**：提取 1 个核心诱饵词，拆分主标题为两部分像素级描述。严禁写"基于词义高亮"，严禁重复/遗漏文字
  - 示例：`"宿舍好物"明黄色圆润字体，"挖到宝了"橙色超大字号+红色手绘圈强调`
- **划重点**：主标题末尾对核心词添加划圈/加粗下划线
- **配色**：主色60%+辅色30%+点缀色10%；中等饱和度+中等明度；与背景强对比；主副标不超过 3 色

## 8. 图层前后关系
- 默认顺序（三分构图）：装饰元素(最上) > 辅助文案 > 副标题 > 人物 > 主标题 > 背景(最底)
- 文字不遮挡人物面部，装饰不干扰核心信息
