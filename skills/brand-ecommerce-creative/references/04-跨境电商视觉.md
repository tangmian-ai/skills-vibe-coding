# Skill 04 · 跨境电商视觉

## Amazon Listing（硬性审核规范，违反直接下架）
| 物料 | 规范 |
|------|------|
| 主图 | **纯白底 RGB(255,255,255)**、产品占比 ≥85%、≥1600px（缩放）、**禁 Logo/水印/促销标签/道具/多角度拼图** |
| 副图 ×6 | 场景图 / 尺寸标注图（inch·lb 单位）/ 功能拆解 / 对比图 / 包装图 / 使用步骤 |
| A+ 内容 | 970px 宽模块化；品牌故事 + 功能矩阵 + 对比表 |

## Amazon 6 张基础结构（按品类替换，不照搬耳机）
| 页 | 类型 | 画面规则 |
|----|------|----------|
| P1 Main Image | 白底主图 | 纯白背景、产品居中、占比 85%+、无任何文字/图标/道具/模特 |
| P2 In Use | 使用展示 | 真人佩戴/喷洒/手持/安装等真实使用状态，展示尺寸和场景 |
| P3 Core Feature | 核心功能 | 浅灰/浅蓝低饱和背景，配短英文卖点和功能示意图 |
| P4 Detail | 细节特写 | 接口、按键、耳罩、喷头、瓶盖、材质等微距细节 + 英文标注 |
| P5 Scenarios | 多场景适配 | 3 个使用场景分区，风格统一，信息清晰 |
| P6 In the Box | 包装/配件/收口 | 包装、配件、使用步骤或套装内容；无包装图时不得虚构认证 |

> 以上是 Amazon Listing 的 6 张结构，不是某个商品的固定模板。每次先做 product-read，再把 In Use/Core Feature/Detail/Scenarios/In the Box 转成该品类的真实画面任务。P1 必须按平台主图规范无文字；P2-P6 必须有英文文案上版。默认每张只出现一个主产品实例，只有多场景、细节拼贴、包装配件或对比页允许多个视角/分区。

## 平台调性差异
- **Amazon（欧美）**：克制、信息效率优先，白底规范严格
- **Shopee/Lazada（东南亚）**：高饱和促销风、角标贴纸文化、Flash Sale 氛围
- **Temu/Shein**：快时尚节奏、真人模特图、多 SKU 平铺
- **独立站 DTC**：editorial 品牌大片风（借鉴 luxury/editorial preset）

## 本地化（与国内最大差异）
- **语言排版**：拉丁字体体系（Inter/Montserrat 类）；德语长单词防溢出；**阿拉伯语 RTL 整体镜像排版**
- **模特与文化**：目标市场肤色/体型多元化；中东市场注意着装尺度；宗教符号回避
- **节日日历**：黑五 / 网一 / Prime Day / 圣诞 / 万圣节 / 返校季 / 斋月 / Diwali（替代 618/双11）
- **单位与规格**：inch/lb/oz 标注；电器注明插头制式与电压

## 合规（按目标市场）
- 美国：FTC 宣称规范（功效需证据）、评论截图需真实
- 欧盟：CE 标识不可滥用、环保宣称防 greenwashing
- 认证图标（FDA/CE/RoHS）只有真实持证才可出现在图上

## Amazon Listing 生产 SOP · 变体 A：平台 Listing 版（四步工序 · 来自内部实操沉淀）

> 适用：Amazon Listing 副图，单张 3:4，六张一组。与工作台流程的映射标注在每步末尾。

### 第 0 步 · 产品多角度提取（素材预处理）
上传产品图，先生成**多角度合集**（正面/侧面/背面/仰视/俯视/细节，合成一张图），
作为后续所有出图的产品保真参考。
→ 对应：② 设计 Agent 的素材预处理；产品参考集注入后续每一次生成。

### 第 1 步 · 视觉风格体系定调
基于产品图（多角度）联网检索同品类跨境爆款风格，反推产品专属【视觉风格体系】，
**固定六大模块输出**：
`整体调性 / 画面质感 / 布光逻辑 / 色彩体系 / 字体规范 / 构图规范`
- 贴合跨境爆款逻辑：**避免纯色背景，主打场景共情、卖点可视化**
- 文案格式统一：字体类型统一、字号/字重层级分明、行距舒适
→ 对应：② 设计 Agent 视觉方向提案 → **H1 设计师确认**（六大模块即确认清单）。

### 第 2 步 · 产品信息识别报告
角色设定「资深跨境电商产品经理 & 跨文化视觉营销专家」，输入
**目标国家/地区 + 电商平台 + 产品图**，输出结构化【识别报告】：
- 品牌名称（中英）/ 产品类型与规格 / 核心卖点 ×6（含数据卖点，联网补充）
- 主色调与辅助色（HEX）/ 设计风格 / 字体风格 / 图案元素
- 目标受众画像（基于目标国社会结构，如：美国郊区家庭 / 日本单身白领）
- 本地化场景建议（欧美-户外草坪/开放式厨房；日本-榻榻米/狭窄玄关）
- 特殊需求开关：模特（族裔/年龄/肤色）/ 场景 / 数据可视化 / 对比图
→ 对应：① 策略 Agent 的 Brief 产出；目标国家+平台 = 工作台的方向参数；
　 卖点与文案进 **H0 人工确认**（价格/认证/宣称强制核对）。

### 第 3 步 · 六张 Listing 单图提示词方案
基于【视觉风格体系】+【识别报告】生成 **6 张（3:4）Listing 单图提示词**，每张包含：
- 主标题 + 副标题（**目标国语言**）、信息布局、排版形式、设计感强调
- 模特族裔按目标国指定（US → diverse/Caucasian；JP → Asian）
- **商品保真锁**：上传商品图作为锁定产品层；图像模型不得重绘商品本体，只能生成背景、场景、氛围、功能示意和辅助组件
- 每屏输出：中文提示词 + **负面提示词** + 比例标注（3:4）
- 每张都是可独立上架的 3:4 成品图；允许部分图不出现产品本体，用功能/材料可视化呈现；全套统一风格无割裂
→ 对应：② 设计 Agent 的生成计划（image_plan）；提示词方案可回 H1 抽查。

### 第 4 步 · 逐屏出图
按屏把确认文案、商品参考与版式规则一起送入图像模型，直接生成完整带字终稿。
**质量档**：H1 前 review 档抽卡 ≤3 轮 → H2 导出 final 档（C4）。
生成后走 ③ 质检：产品层与上传图像素/结构比对 + 文字与确认稿一致 + 平台合规 + **C4 视觉质量判定**。
→ 对应：② 批量生产 → ③ 质检 Agent → H2 终审。

### 高质量生图要点（C4 · 跨境专用）
- **Visual DNA 锚点**：产品造型/包装/LOGO/材质/光影全套锁定（借鉴 [product-shots](https://github.com/motiful/product-shots)）
- **Amazon 主图**：合规规则写入 Prompt 字段（白底 RGB255/占比≥85%/无文字），非事后抠图
- **副图范式**：产品 Hero + 生活方式 + 功能可视化信息卡（参考 `物料/离线Demo七方向/S04-amazon-headphone/` 离线案例）
- **模型**：产品保真用 gpt-image-2；场景氛围可 gemini-3-pro-image；终稿禁止 draft 档直接交付
- **英文文案**：图像模型直出后必须 OCR 校验；价格、认证、规格等无依据内容禁止生成

## 详情页生产 SOP · 变体 B：海外社媒引流版（三步 · 来自内部实操沉淀）

> 适用：Instagram Story / TikTok / Pinterest 站外引流素材，**10 屏 9:16 竖屏**。
> 与变体 A 同源，差异：跳过风格定调步（直接从识别报告到提示词）、每屏强制 CTA、
> 生图模型推荐 Nano Banana Pro。
> （SOP 原文"10 屏(2:3)"与"9:16"自相矛盾，按目标平台特性归一为 9:16。）

### 第 1 步 · 产品识别报告
与变体 A 第 2 步同一套提示词（目标国家/地区 + 电商平台 + 产品图 → 结构化识别报告），
初始化示例：美国 + Amazon。
→ 对应：① 策略 Agent Brief → **H0 确认**。

### 第 2 步 · 10 屏分屏提示词
基于【识别报告】+【目标国家/市场】生成 10 屏（9:16）方案，在变体 A 第 3 步基础上追加：
- **每屏必带 CTA 按钮**，文字为目标国语言，格式统一：`SHOP NOW >` / `LEARN MORE >`，
  箭头符号全套统一
- 排版按**杂志级**标准（信息布局/排版形式/设计感逐屏详述）
- 产品保真硬约束、模特族裔本地化、30s 抓视觉、全套统一无割裂：与变体 A 相同
→ 对应：② 生成计划；CTA 文案随文案包进 H0 一次性确认。

### 第 3 步 · 逐屏出图
一屏一屏投喂提示词生图，模型推荐 **Nano Banana Pro**（社媒风格化表现好）。
→ 对应：② 批量生产 → ③ 质检（CTA 文字 OCR 校验 + 保真比对）→ H2 终审。

## 详情页生产 SOP · 变体 C：风格复刻版（有参考图时）

用户提供竞品/参考图时，走 **C3-参考图反推与风格复刻**，配合本 Skill 识别报告：
- **主图复刻**：多参考图 + 产品图 → 6 张 3:4 单图
- **A+ 复刻**：参考 A+ 长图 → 6 屏 21:9 横屏，上下拼接成 21:54 长图
- 红线：只学风格/排版/色调，禁抄参考图文字文案与模特长相（详见 C3）

### 变体选择逻辑（编排层路由）
| 目标场景 | 用哪个变体 | 关键差异 |
|---------|-----------|---------|
| 平台内 Listing | 变体 A | 6 张 3:4 单图，先定风格体系，重卖点拆解 |
| 站外社媒引流（Story/TikTok/Pinterest） | 变体 B | 10 屏 9:16，每屏 CTA 导流，重 3 秒抓眼 |
| 有参考图/竞品图，要"做成这种感觉" | 变体 C | C3 反推复刻，主图 6 张 3:4 / A+ 21:54 长图 |

### 文字渲染策略（本 Skill 特例）
- **拉丁语系文字可由图像模型直出**（英文渲染可靠性高，且详情页文字与画面融合度要求高）
- 中文、阿拉伯语与小语种同样以确认稿直接进入生图 Prompt，并在成图后 OCR 严查
- 价格、认证标识、规格参数必须先有确认依据；无依据时禁止生成，不走后置叠加

## 强制核对（H0 节点）
- 价格币种 / 促销时区 / 认证资质 / 目标市场语言文案（母语审校）
- 识别报告中的卖点宣称（FTC/CE 证据）、模特族裔与文化适配
