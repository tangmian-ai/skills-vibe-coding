# 行业人像特征 Skill

本 Skill 旨在为小红书人像封面生成提供具体的行业赛道人像特征描述。

## 1. 核心路由逻辑

Agent 在执行人像生成任务时，应根据用户指定的赛道或内容主题，调用 `references/` 目录下的对应文件获取 Prompt 关键词。

### 规则 1：虚拟角色优先 (Virtual Character Priority)
- **触发条件**：用户明确指明有虚拟形象要求（如“3D”、“动漫”、“卡通”、“虚拟IP”）。
- **执行动作**：必须结合 `references/虚拟角色.md` 和其他赛道文件内容进行输出。
- **说明**：即使属于职场或教育赛道，若用户指定虚拟风格，则人像的**风格质感**应遵循 `references/虚拟角色.md`，而**动作场景**遵循对应赛道文件。

### 规则 2：赛道映射 (Track Mapping)

请根据用户内容归属，精确调用以下文件：

- **职场赛道**：调用 `references/职场赛道.md`
  - 适用：求职、办公、职场经验分享等。
- **校园/学习赛道**：调用 `references/校园学习赛道.md`
  - 适用：学生、考试、资料分享、校园生活等。
- **自媒体起号赛道**：调用 `references/自媒体起号赛道.md`
  - 适用：运营干货、涨粉攻略、变现指南等。
- **通用/生活赛道**：调用 `references/通用生活赛道.md`
  - 适用：母婴、家居、旅行、情感、种草、地产、美食、穿搭、金融、健身、彩妆及其他未列出的场景。

## 2. 知识库索引

- **虚拟角色**：`references/虚拟角色.md` (必读，若命中虚拟形象需求)
- **职场赛道**：`references/职场赛道.md`
- **校园/学习赛道**：`references/校园学习赛道.md`
- **自媒体起号赛道**：`references/自媒体起号赛道.md`
- **通用/生活赛道**：`references/通用生活赛道.md`
