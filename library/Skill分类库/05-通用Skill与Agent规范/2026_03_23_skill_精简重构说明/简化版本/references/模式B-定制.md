# 模式 B：博主风封面定制

触发：1图（人物图）+ 文案

## 强制定义项
- **人物** `[人物维度]`：基于图1特征，按需响应用户指令调整。若用户无指令，绝对保持图1的动作与表情，严禁脑补不存在的动作/视线
- **内容** `[海报主题]` + `[文案信息]`：使用用户提供的文案与主题

## 风格生成项（按规则生成）
- **氛围** `[背景维度]` + `[装饰元素]`：结合用户主题，按 prompt-公式 规则生成
- **视觉** `[版式框架]` + `[字体样式]` + 配色：按 prompt-公式 中的四大构图、高亮策略、配色规则生成
- **人像赛道**：从对应赛道人像规则获取场景/动作特征
