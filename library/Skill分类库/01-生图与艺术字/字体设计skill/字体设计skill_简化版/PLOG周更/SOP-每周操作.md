# PLOG 周更 SOP（每周 5 分钟版）

> 给"任何同事接手都能照着做"的操作手册。
> 总耗时：人工 5 分钟 + AI 30 秒。

---

## 你需要

- [ ] 一台能上小红书的设备（手机或电脑）
- [ ] 一个 AI 工具（任选其一）：
  - Cursor 聊天（推荐，模型最强）
  - Claude Desktop（推荐）
  - 钉钉智能体「PLOG选题总监」（贴合工作流）
  - 通义千问 App（备用）
- [ ] 5-6 分钟时间

---

## 完整步骤

### 第 1 步：复制本周文件夹（30 秒）

1. 进入 `PLOG周更/` 目录
2. 复制 `_周报模板/` 整个文件夹
3. 重命名为 `YYYY-Www/`，例如：
   - `2026-W19/`（2026 年第 19 周）
   - `2026-W20/`（下一周）
4. 周编号查询：[ISO 周历](https://www.epochconverter.com/weeks/2026)，或在 Mac 终端跑 `date +%Y-W%V`

### 第 2 步：小红书搜 + 截图（4 分钟）

1. 打开**小红书 App**（电脑端搜不到完整笔记）
2. 搜本周关键词，例如：
   - `文字plog 五月`
   - `字体海报 春天`
   - `拼贴plog 旅游`
   - `手写体plog`
3. 切换到 **「最热」** 排序（关键，不要用默认）
4. 挑 **6-8 张** 符合条件的封面：
   - ✅ 点赞 **1k+**（真实高赞）
   - ✅ 视觉风格**一致**（不要混搭多种公式）
   - ✅ 当周/近期发布优先
5. 截图保存到 `YYYY-Www/截图/`，命名 `01.jpg` ~ `08.jpg`

**挑图小贴士**：
- 不要看标题党，看封面构图、字体、配色
- 如果一组挑不到 6 张同风格，换关键词重搜
- 避免选有明显水印/二维码的图（会干扰 AI 判断）

### 第 3 步：扔给 AI（30 秒）

1. 打开你选的 AI 工具
2. 打开 `PLOG周更/提示词-一次性看图.md`
3. 复制 **横线之间的全部内容**（不要复制使用说明部分）
4. 粘贴进 AI 对话框
5. 把本周文件夹 `截图/` 里的 6-8 张图**全部拖进去**
6. 发送

### 第 4 步：粘贴入表（30 秒）

1. AI 会返回：「本周大主题」一句话 + 一张 markdown 表格
2. 复制表格内容
3. 粘贴进本周文件夹的 `选题表.csv`：
   - **方法 A**：用 Numbers / Excel 打开 csv，直接粘贴 markdown 表格内容（会自动分列）
   - **方法 B**：在浏览器把 markdown 表格复制 → 用 [tableconvert.com](https://tableconvert.com/markdown-to-csv) 转成 CSV → 替换 csv 文件
   - **方法 C**：直接粘贴进钉钉 AI 表格的对应字段

### 第 5 步：交付给设计师（30 秒）

把以下内容打包发给设计师：
- `YYYY-Www/截图/` 整个文件夹（参考用）
- `YYYY-Www/选题表.csv`（任务清单）
- 一句话说明：「本周大主题：XXX，请按表格 6-8 个小主题各出一版设计」

## 常见问题

### Q1：AI 返回不是表格 / 格式乱了
**原因**：提示词没复制完整，或者 AI 模型不支持 markdown 表格。
**解决**：
- 重新复制完整提示词
- 换一个支持表格输出的模型（Claude / GPT-5.5 / 千问 VL Max）

### Q2：文案不够小红书味
**原因**：AI 的默认风格偏书面。
**解决**：在原提示词末尾加一句：
> 「文案要更口语化，像 25 岁女生发朋友圈，不要"分享""记录"等套话」

### Q3：6-8 个小主题场景重复
**原因**：AI 倾向往同一类场景靠。
**解决**：在原提示词末尾加一句：
> 「6-8 个小主题之间必须有明显场景差异：至少包含1个旅游、1个美食、1个居家、1个其他」

### Q4：视觉关键词太抽象（"好看""复古"）
**解决**：在原提示词末尾加一句：
> 「视觉关键词必须含具体颜色名（莫兰迪蓝/奶油白/灰绿），构图位置（上下夹/左右拼），不要用模糊词」

### Q5：大主题写得太宽（"复古风"）
**解决**：在原提示词末尾加一句：
> 「大主题必须含3要素：①构图方式 ②字体/标题特征 ③配色，不能只用一个词概括」

### Q6：本周挑不到 6 张同风格的图
**解决**：
- 换关键词（试试更具体的，如「奶油色 plog」）
- 降低标准到 5 张也可以
- 或者本周用上周的大主题（连续两周做同一公式，做深做透）

## 文件夹命名规则

```
PLOG周更/
├─ 提示词-一次性看图.md        ← 永久复用
├─ SOP-每周操作.md            ← 永久复用
├─ README.md                  ← 永久复用
├─ _周报模板/                 ← 永久复用，每周复制
│   ├─ 截图/
│   └─ 选题表.csv
├─ 2026-W19/                 ← 第 19 周
├─ 2026-W20/                 ← 第 20 周
└─ ...
```

**为什么周编号用 W 不用日期？**
- 月份会跨周，日期不直观
- W 编号方便对齐 OKR / 周报 / 排期
- 国际通用 ISO 8601 标准
