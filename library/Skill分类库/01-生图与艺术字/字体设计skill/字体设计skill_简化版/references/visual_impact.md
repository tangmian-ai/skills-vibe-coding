# 视觉冲击 (Visual Impact)

适用：促销、游戏、赛博、酸性、机甲、金属

## 风格词库
- **促销与商业**：强烈促销氛围立体艺术字、多层立体渐变效果、3D卡通风格电商促销
- **机械与金属**：机甲字体、矢量机甲字体、机械金属字体设计、亮银色金属拉丝质感、青铜器金属质感
- **赛博与酸性**：霓虹灯管风、软管艺术字体、酸性艺术概念性混合创意字体设计、液态铬金属质感

## 视觉要求
- **维度**：通常为 **3D艺术字体设计**
- **字形与材质（按语境选用）**：
  - 促销/商业语境（双11/年货节/打折等）→ [膨胀气球]、[夸张张力]、[卡通立体光泽]、彩色多层渐变、明亮饱满，严禁暗黑/机械/锈蚀
  - 机甲/金属语境 → [机械管线]、[尖锐棱角]、金属拉丝/青铜质感、冷硬工业风
  - 赛博/酸性语境 → [液态流动]、霓虹发光、液态铬、酸性撞色
- **色彩**：描述 [渐变]、[撞色]、[高光]、[反光纹理] 等强视觉元素
- **背景收敛**：机械管线/电路/光效等元素必须收敛在文字轮廓内，严禁延伸到背景区域
- **反悖论**：严禁宋体、楷体等传统书写风格（国潮混搭除外）

## 示例
- 促销3D：`主标题"年货节狂欢 好礼享不停" 两排排列，是具有强烈促销氛围的立体艺术字。笔画线条流畅且富有动感（带立体光泽），纯白色背景。`
- 液态金字：`"馬到功成"，字体结构源自黑体但经过大幅形变形成致密而富有流动感的抽象符号（笔画以超粗块面相互挤压融合，笔画末端如融化的金液自然流淌拉长），字体完全呈现液态黄金质感（高反射率、强烈的高光与深邃的暗部对比），纯黑色背景。`
- 霓虹灯管：`荧光绿色的"营业中"字体设计，软管艺术字体，霓虹灯管风（轮廓式笔画，发光描边，线条细长柔和，具有流动感，营造出迷幻而复古的赛博朋克氛围），纯黑色背景。`
- 机甲高达：`3D渲染的文字"机甲出击"，白色、蓝色和红色的高达风格的立体机械字（带有机器数字元素），工业风，纯黑色背景。`
