### 技能规范

#### 核心原则
1. **艺术整体性 (Artistic Unity)**：
    - **整体设计**：这是一个**艺术字设计**技能，而非简单的文字排版。所有元素（装饰、副标、标签）必须围绕主标题进行设计，形成一个有机的视觉整体。
    - **装饰理性 (Decoration Rationality)**：
        - **默认置换**：若用户未明确要求装饰，默认优先考虑**字形元素置换**（如用星星替换点画、用闪电替换竖画），而不是强制添加外部装饰。
        - **按需外化**：仅在用户明确要求（如“周围有星星”、“背景有祥云”）时，才将装饰置于文字周围或背景。
        - **拒绝纹理**：严禁装饰像背景纹理一样无意义地出现在画面上，必须与文字主体有结构上的关联。
    - **可移植性**：设计必须考虑后续用途（如海报合成），背景必须干净，主体必须完整，避免脏乱杂。
    - **字间关系 (Inter-character Relationship)**：
        - **字组思维**：严禁将每个字视为独立个体设计。必须描述字与字之间的**连接逻辑**（如连笔、穿插、共用笔画）或**整体动势**（如统一向右倾斜、呈波浪形排列）。
        - **紧凑排版**：除非特定留白需求，否则字间距应紧凑，形成一个不可分割的视觉图形。

2. **文字精准性 (Text Accuracy)**：
    - **逐字拆解**：Prompt 中必须将用户提供的文字内容逐字列出，格式为 `仅包含N个字："X"、"X"、"X"...，不得增加、遗漏或替换任何一个字`。例如用户要求"新春大吉"，则 Prompt 中必须写 `仅包含4个字："新"、"春"、"大"、"吉"，不得增加、遗漏或替换任何一个字`。
    - **字数前置**：在主体文字描述的**最前面**声明精确字数，如 `四个字"新春大吉"`。
    - **禁止衍生**：严禁 AI 自行添加额外的汉字、标点、装饰文字。用户给几个字就是几个字，**一字不多，一字不少**。

3. **结构分隔律 (Structural Separation)**：
    - **句号分隔**：主要设计模块之间必须使用句号 `。` 严格隔开，避免 AI 混淆修饰关系。
    - **标准顺序**：`[背景]。[维度声明] [主体设计]。[副标/装饰设计]。[整体/比例]`。
    - **维度前置**：必须在 Prompt 开头（背景之后）明确声明是 **“3D艺术字体设计”** 还是 **“平面艺术字体设计”**，严禁模棱两可。

3. **字形设计核心 (Shape Design Core)**：
    - **设计感可见性 (Visible Design)**：所有文字（即使是极简）必须有**肉眼可见的设计痕迹**（如连笔、延长、变形、错位、断开）。严禁生成平庸的电脑标准字库体。
    - **字形比喻法 (Shape Metaphor)**：使用物理物象（如“舞动的丝带”、“堆叠的积木”、“流动的液体”、“锋利的刀刃”）来具体描述笔画形态，拒绝“大气”、“好看”等抽象形容词。
    - **字形≠材质**：严禁将材质效果（如“金属光泽”）混淆为字形设计。

4. **色彩精准化 (Color Precision)**：
    - **拒绝笼统**：严禁使用“红黄蓝撞色”等模糊描述。必须明确：**文字主体色、描边色、装饰色**。
    - **智能背景配色 (Contrast Logic)**：
        - 用户指定背景时：严格执行，且保持干净纯色。
        - 用户未指定时：**强制执行高对比度逻辑**：
            - **浅色/亮色字** -> 强制搭配 **“干净的纯黑色背景”**（**严禁**为了在白底显示浅色字而强行加描边，必须换背景色）。
            - **深色/暗色字** -> 强制搭配 **“干净的纯白色背景”**。

5. **背景纯净原则 (Clean Background)**：
    - **背景前置**：背景描述必须放在 Prompt 最前面。
    - **干净纯色**：除非用户强制要求场景，否则默认输出 **“干净的纯[色]背景”**。
    - **光影隔离**：文字的发光/投影/倒影属于主体层级，必须紧跟主体描述，**严禁**写在背景描述中。

6. **排版与比例 (Layout & Ratio)**：
    - **比例后置**：比例必须写在 Prompt 最后，格式为 `比例宽:高`。
    - **智能计算**：
        - **≤2 字**：比例 1:1。
        - **3-8 字**：比例 4:3。
        - **>8 字**：比例 16:9。

7. **智能推导链 (Inference Chain)**：
    - **应对模糊需求**：当用户只提供文案（如“设计'龙'字”）时，必须触发推导：
        1. **分析语义**：“龙” -> 东方/霸气/传统。
        2. **匹配场景**：东方美学。
        3. **调用技法**：书法飞白/龙鳞纹理。
        4. **补全参数**：黑金配色/4:3比例/纯白背景。
    - **应对抽象形容**：当用户输入“高端”时，自动映射为“现代极简_衬线体_黑金配色”。

8. **悖论融合策略 (Fusion Strategy)**：
    - **应对强制冲突**：当用户强制要求风格悖论（如“赛博宋体”），严禁直接拒绝或生硬拼接，必须执行**融合转化**：
        1. **骨架重塑**：保留一种风格的骨架（如宋体笔画），融入另一种风格的材质（如霓虹灯管）。
        2. **材质置换**：将传统材质（如水墨）用现代物理属性（如液态金属）重新演绎。
        3. **光影统一**：用统一的光影环境（如赛博蓝紫光）强行统合冲突元素。

#### 质量标准
1. **维度明确**：Prompt 开头必须清晰声明 3D 或平面。
2. **字形设计**：必须描述具体的笔画变形（连笔/延长/错位）。
3. **装饰合理**：装饰优先内化置换，无要求时不强加外部装饰。
4. **色彩对比**：严格执行“浅配深、深配浅”的背景逻辑，拒绝不必要的描边。
5. **逻辑自洽**：不存在未经融合的生硬悖论（如“水墨金属”）。
6. **信息完备**：即使是极简输入，生成的 Prompt 也必须包含所有 5 大要素。

#### 禁忌
1. **禁忌风格悖论 (Style Paradox)**：
    - **维度悖论**：非 3D 类设计严禁出现“霓虹灯管”、“充气”、“倒角”等 3D 专属效果。
    - **材质悖论**：水墨书法严禁搭配“金属光泽”、“霓虹发光”等现代材质；极简几何严禁搭配“斑驳锈迹”等复古材质。
    - **时代悖论**：传统宋体/楷体严禁搭配“赛博朋克”、“故障艺术”等未来风格；涂鸦风格严禁搭配“古风”、“禅意”描述。
    - **物理悖论**：液态/水流字体严禁出现“锐利切角”、“硬朗折痕”；金属字体严禁出现“随风飘动”等柔软描述。
    - **例外条款**：若用户**强制要求**上述悖论组合（如“赛博宋体”），则不受此限，但必须执行**悖论融合策略**。
2. **禁忌贴纸装饰**：严禁装饰元素像贴纸一样悬浮在文字表面，必须融入设计。
3. **禁忌结构混乱**：严禁混用逗号连接背景、主体和副标，必须用句号断开。
4. **禁忌风格漂移**：严禁将“3D字体”做成“3D插画”，反之亦然。
5. **禁忌文字粘连**：在设计复杂艺术字时，必须强调“保持文字结构的可识别性”。
6. **禁忌悬浮干扰**：严禁装饰物遮挡文字的核心识别区域，严禁出现无物理支撑的悬浮缠绕物。
7. **绝对禁止中间工具调用**：在读取技能文件、构建提示词的过程中，严禁调用任何名为scene_tool 的工具或搜索引擎（web_search）。只有在提示词构建完成后，才允许调用图片生成工具来出图。

#### 场景判别（思考步骤，非工具调用）

在生成提示词之前，你需要先通过自身推理分析用户需求，判断所属的设计氛围类型（不要尝试调用任何外部工具来完成此步骤）：

- **东方美学**：书法、篆刻、民俗、国潮、传统节日。
- **现代极简**：科技、时尚、商务、文艺、简约现代。
- **视觉冲击**：商业促销、游戏、赛博、酸性、机甲、金属。
- **材质模拟**：自然、手工、玻璃、水、毛绒、布料、木材、食物等。
- **创意装饰**：涂鸦、POP、故障、像素、拼贴、光影特效。
- **通用设计**：无明确倾向，根据语义归类。

**输出要求**：
- 仅输出 Prompt。
- 严格遵循结构：`[干净的背景]。[维度声明] [字数+主体文字] ([字形细节]) ([材质/色彩])。仅包含N个字："X"、"X"...，不得增加、遗漏或替换任何一个字。[副标/装饰]。[比例]`。
