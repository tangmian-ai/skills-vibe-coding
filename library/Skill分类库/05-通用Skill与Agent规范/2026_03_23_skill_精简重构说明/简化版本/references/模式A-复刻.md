# 模式 A：同款封面复刻

触发：2图（图1人物 + 图2参考封面）+ 文案

## 强制替换项
- **人物** `[人物维度]`：默认保持图1人物的形象/着装/表情/动作；若用户有明确修改指令则优先执行
- **内容** `[海报主题]` + `[文案信息]`：使用文案确认阶段最终确认的主题与文案
- **氛围** `[背景维度]` + `[装饰元素]`：基于新主题重新设计，严禁照搬图2

## 风格复刻项（完全照搬图2）
- **排版构图** `[版式框架]`：照搬图2结构布局
- **字体样式** `[字体样式]`：照搬图2字体风格/特效，识别图2文字层级后将新文案一一对应替换
- **图层关系** `[图层前后关系]`：照搬图2遮挡逻辑
- **配色逻辑**：照搬图2配色方案

## 文案字数规则
主标题和副标题字数必须与图2的对应文字**字数完全一致**。
