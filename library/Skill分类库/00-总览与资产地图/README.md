# Skill 分类库

本资料库为桌面快捷归档，所有内容均从原路径复制，源文件未移动。

## 目录说明

- `00-总览与资产地图`：AI 作品整理报告与本说明。
- `01-生图与艺术字`：艺术字/字体设计、生图方法、参考图控制、ComfyUI 海报工作流和 Prompt 库。
- `02-视频与动态视觉`：视频反推、镜头语言、视频 Prompt 工作台。
- `03-内容生产与自动化工作流`：内容生产 SOP、Dify 工作流 YAML、热点评估与素材流程。
- `04-品牌电商与投放视觉`：品牌 Kit、社媒、节日、电商、直播、印刷和 KV 延展。
- `05-通用 Skill 与 Agent 规范`：路由、合规、设计助手、Skill 模板与重构规范。

## 推荐使用顺序

1. 做静态视觉：先看 `01-生图与艺术字`。
2. 做视频项目：先看 `02-视频与动态视觉`，再看 `03-内容生产与自动化工作流`。
3. 做商业物料：先从 `04-品牌电商与投放视觉` 选渠道与场景。
4. 写或维护 Agent Skill：使用 `05-通用 Skill 与 Agent 规范` 的模板、路由和合规资料。

## 维护规则

- 更新任一技能时优先改源项目，再手动替换本资料库对应副本。
- `prompt库.docx` 是旧素材库；`生图 Skill 2026 更新整理版.docx` 是当前可执行版本。
- 需要对外展示时，请对真实人物、品牌、平台截图及可识别客户数据做授权和合规复核。
