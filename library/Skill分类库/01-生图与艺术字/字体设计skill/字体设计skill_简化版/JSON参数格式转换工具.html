使用提示：
• JSON → 纯文本：提取 {argument default="值"} 中的默认值，生成纯文本
• 纯文本 → JSON：标记可变部分，自动生成参数模板
• 翻译为中文：支持任意语言翻译为中文，开启「保留 JSON 参数结构」后只翻译文本和 default 值，name 值也一并翻译
• MD → 纯文本：去除 Markdown 所有语法标记（标题#、加粗**、链接、代码块、表格等），输出干净文本
• JSON结构 → 文本：将完整的 JSON 结构化 Prompt（含嵌套对象、数组、面板）摊平为可直接使用的自然语言描述
• 翻译使用 Google Translate 接口，需要网络连接
