# 设计需求问卷模板

阶段一需求解构时按设计类型查阅。信息不足时主动追问，但单次最多 3-4 个最关键问题，避免审讯式提问。已有答案的不重复问。

## 通用必问项（所有类型）

1. **核心目的**：这张设计要解决什么问题？（宣传/识别/传达/氛围/转化）
2. **使用场景**：投放渠道 + 展示环境（屏幕/印刷/户外）
3. **目标受众**：年龄层、审美倾向
4. **尺寸/比例**：精确像素或比例（印刷需 DPI、出血）
5. **已有素材**：品牌 Logo、品牌色、产品图、指定字体、必用文案
6. **风格倾向**：口述风格词或参考图（模糊则备 2-3 方向供选）
7. **禁忌**：明确要避免的元素/风格

## 分类型深挖问题

### 海报 / 主视觉 KV
- 主题与核心信息是什么？最优先传达的一句话？
- 是否有活动信息（时间/地点/嘉宾/报名方式）？
- 信息层级：哪些是主、哪些是次、哪些可省？
- 是否需要产品/人物主视觉图？用户提供还是 AI 生成？
- 氛围：盛大/活泼/文艺/科技感/高级？

### Logo / 品牌标识
- 品牌名称（中英文全称）+ 是否需要副标/slogan？
- 行业属性 + 品牌性格（专业/亲和/创新/传统/奢华）？
- Logo 类型倾向：纯文字/图形+文字/抽象图形/具象图形/字母标？
- 应用场景（名片/门头/App图标/绣标），最小使用尺寸？
- 配色限定或偏好？是否需要黑白单色版本？
- 有无品牌故事/寓意希望融入？

### Banner / 横幅 / 头图
- 投放平台精确尺寸？（公众号头图 900×383 / 小红书 1080×1440 / 微博 1920×1080 / 官网 banner 等）
- 是否多端适配（PC+移动）？安全区要求？
- 核心文案 + CTA 按钮文字？
- 是否促销/活动性质？有无价格/折扣信息？
- 与落地页风格是否需一致？

### 封面（专辑/书/报告/课件）
- 载体类型：实体书/电子书/音乐专辑/年度报告/PPT课件？
- 标题 + 副标题 + 作者/署名？
- 体裁调性（学术严肃/商业专业/文艺清新/流行活力）？
- 是否有系列？需统一视觉体系？
- 是否需要留 ISBN/条码位？

### 插画
- 插画用途（配图/主视觉/装饰/故事叙述）？
- 主题与场景描述：画面里有什么？发生什么？
- 绘画风格倾向（扁平/手绘/水彩/3D/赛博朋克/国潮/日式…）？
- 画面情绪（温暖/孤独/欢乐/神秘/史诗）？
- 是否有人物？人物特征（年龄/性别/服饰/表情）？
- 构图要求（横构图/竖构图/全景/特写）？

### 包装设计
- 产品类型 + 包装形态（盒/瓶/袋/罐/礼盒）？
- 产品卖点与目标人群？
- 是否需要展开刀模图（平面展开 + 立体效果）？
- 必含信息（品名/配料/净含量/条码/生产信息）排版要求？
- 材质工艺影响（哑光/亮面/烫金/凹凸）？

### 名片
- 双面/单面？横版/竖版？
- 必含信息（姓名/职位/公司/电话/邮箱/地址/网站/二维码）？
- 行业气质 + 个人风格偏好？
- 印刷工艺（烫金/凹凸/特种纸）影响设计？

### 邀请函
- 活动性质（婚礼/商务/发布会/展览/庆典）？
- 必含信息（时间/地点/着装/流程/回复方式）？
- 调性（庄重/浪漫/活泼/极简）？
- 形式：电子版/印刷版/折页？

### 社媒配图（小红书/朋友圈/公众号插图）
- 平台 + 图位（封面/内页/九宫格）？
- 是否带文字 overlay？文字内容？
- 是否需统一系列感（多图一组）？
- 调性是否贴合账号人设？

### UI / App 视觉
- 所属端（iOS/Android/Web/小程序）+ 屏幕类型？
- 是否需符合某设计系统（Material/Apple HIG/品牌组件库）？
- 核心功能与视觉焦点？是否需空状态/引导图？
- 配色是否沿用品牌色？暗色/亮色模式？

## 需求解构输出格式

向用户复述理解，示例：

> "我理解你需要的是一张 **[类型]**，用于 **[场景/渠道]**，面向 **[受众]**。核心要传达的是 **[主信息]**，重点突出 **[焦点]**。风格上倾向 **[方向]**，尺寸 **[规格]**。你已提供 **[素材]**。
>
> 设计上我认为需要重点处理的是 **[1-2 个专业判断，如信息层级/视觉焦点/氛围营造]**。
>
> 这个理解对吗？确认后我去找些契合的参考图来对齐方向。"
