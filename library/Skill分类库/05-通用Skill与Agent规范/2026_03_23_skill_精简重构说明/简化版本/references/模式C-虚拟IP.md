# 模式 C：虚拟IP封面定制

触发：0图 + 文案

## 强制定义项
- **内容** `[海报主题]` + `[文案信息]`：使用用户提供的文案与主题

## 人物生成分支
- IF 用户指定虚拟/卡通形象（3D、动漫、卡通、虚拟IP）→ 风格质感用人像-虚拟角色，动作场景用对应赛道人像规则
- ELSE IF 用户指定真实人像 → 仅用对应赛道人像规则
- ELSE 默认 → 生成虚拟卡通形象，用人像-虚拟角色

## 风格生成项（按规则生成）
- **氛围** `[背景维度]` + `[装饰元素]`：结合用户主题，按 prompt-公式 规则生成
- **视觉** `[版式框架]` + `[字体样式]` + 配色：按 prompt-公式 中的四大构图、高亮策略、配色规则生成
