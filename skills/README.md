# Skill Projects

Each directory in this folder is a standalone skill project. `SKILL.md` defines its trigger and delivery contract; support files are kept beside it rather than hidden in a general archive.

## Visual Production

- `image-generation-production`: commercial AI-image workflow and reusable prompting.
- `typography-art-text`: Chinese art text, 3D type, and stylized lettering.
- `brand-ecommerce-creative`: brand and channel-specific commercial adaptation.
- `app-resource-adaptation`: App in-product marketing placements.
- `creative-qc-compliance`: visual QA and commercial risk review.
- `design-assistant`: brief-to-direction design workflow.

## Project Discovery

- `project-charter-interviewer`：先检索、再判断，产出证据日志、风险登记与可供决策的完整项目章程。

## Video & Content

- `video-camera-movement`: camera-motion vocabulary and prompts.
- `reverse-video-prompt-completeness`: reverse-prompt completeness audit.
- `cinematic-director`: film direction, continuity, shot lists, and AI-video plans.
- `content-pipeline`: topic-to-production workflow and records.

The repository's `library/Skill分类库/` contains related legacy material, templates, media, and working examples. It is not the install surface.
