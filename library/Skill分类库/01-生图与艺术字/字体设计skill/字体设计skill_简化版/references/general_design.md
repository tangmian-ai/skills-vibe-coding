# 通用设计 (General Design)

适用：无明确风格倾向、或仅提供基础文案。强调排版美学、字体结构微调和广泛适用性。

## 风格词库
- **无衬线/黑体**：无衬线字体、黑体、纤细黑体变体、极简无衬线
- **衬线/宋体**：宋体、衬线宋体、宋朝字体
- **圆润/亲和**：圆角字、幼圆、纤细黑体变体加圆角
- **通用修饰**：哑光质感、微光晕、基础渐变色、干净阴影、清晰易读、排版紧凑、结构平衡

## 视觉要求
- **字形**：避免过度夸张变形，保持高可识别性，可适当 [圆角处理] 或 [斜切处理]
- **色彩**：经典双色搭配或柔和单色渐变，避免强烈撞色
- **背景**：强制极简纯色（纯白/纯黑/极浅灰）

## 示例
- 黑体通用：`干净的纯白色背景。平面艺术字体设计"品牌力量"（现代无衬线黑体风格，字形结构平衡，笔画粗细均匀，在笔画的转折处做轻微的圆角处理，字间距适中，保持极高的可识别性）（深蓝色哑光质感，无描边）。比例16:9`
- 衬线优雅：`干净的纯黑色背景。平面艺术字体设计"艺术展览"（经典衬线宋体风格，横细竖粗，笔画末端带有优雅的装饰性衬线，整体排版紧凑）（白色主体，带有极弱的柔和光晕）。比例4:3`
- 渐变立体：`干净的纯白色背景。3D艺术字体设计"年度报告"（基础厚重的立体无衬线字形，正面平整，边缘带有倒角，无多余装饰）（从橙色到红色的柔和渐变材质，侧面为深红色，带有干净的落地阴影）。比例16:9`
