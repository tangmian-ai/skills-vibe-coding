# Skill C4 · 高质量生图规范

> 方向 Skill（01~09）管「做什么、什么尺寸、什么平台规则」；
> 本 Skill 管「怎么出图才够高质量、用什么模型、怎么验收」。
> 借鉴：[motiful/product-shots](https://github.com/motiful/product-shots)、[UhuruAI/fantastic-posters](https://github.com/UhuruAI/fantastic-posters)、[K-higgsfield-skills](https://github.com/konankikesava/K-higgsfield-skills)

---

## 一、质量分级（全流程默认策略）

| 阶段 | 质量档 | 用途 | 模型建议 | 通过标准 |
|------|--------|------|---------|---------|
| 探索 | draft | 方向试探、构图验证 | 快速模型 / quality=low | 结构可读即可，不交付 |
| 评审 | review | H1 视觉方向确认 | quality=medium | 风格统一、卖点可读 |
| **交付** | **final** | H2 终审导出 | **gpt-image-2 / gemini-3-pro-image** + quality=high | 商业可用、无 AI 廉价感 |
| 印刷/大屏 | print | 线下物料 / 4K 延展 | final 出图 + **超分增强**（C3 超高清指令） | ≥300dpi 等效、细节不糊 |

**原则**：H2 导出只允许 `final` 档；draft 不得进入终稿交付链路。

## 二、模型路由（按任务类型，非用户手动选）

| 任务 | 优先模型 | 原因 |
|------|---------|------|
| 产品保真 / Amazon 主副图 / 多角度 | gpt-image-2 | 产品轮廓、包装文字、材质还原强 |
| 生活方式场景 / 黄金时段摄影感 | gemini-3-pro-image-preview | 光影氛围、人物场景自然 |
| 社媒原生感 / 快速抽卡筛选 | nano-banana-pro 类 | 风格化快，仅用于 draft/review |
| 中文长标题融合（需直出时） | gpt-image-2 | CJK 渲染相对可靠 |
| 超分 / 修复多次编辑变糊 | 超高清增强流程（C3） | 仅增强画质，**禁止改变人物/产品特征** |

编排层在 `image_plan` 中为每屏标注 `quality_tier` + `model`，② 按表执行。

## 三、出图前自检（14 点 · 渲染前必过）

> 源自 product-shots 的 pre-render self-check，适配全方向。

1. 已挂载 C0 路由 → 输出语言 / 平台正确
2. 已挂载 C1 → Brand Kit 已提案或锁定（色彩/字体非硬编码平台 VI）
3. 有商品图 → 多角度参考集 / ControlNet 基准已注入
4. 有参考图 → C3 复刻红线已写入提示词（禁抄文字/模特脸）
5. 产品保真咒语已写入每条 Prompt（造型/颜色/LOGO/材质 1:1）
6. 负面提示词已写入（变形/低清/牛皮癣/假标签/畸形手/风格割裂）
7. 画幅比例与方向 Skill 一致（3:4 / 2:3 / 9:16 / 21:9…）
8. 文字策略已选定：引擎上版 or 模型直出（直出则标记 OCR 必查）
9. 光影描述具体（硬侧光/柔和窗光/三点布光），非「beautiful lighting」
10. 材质描述具体（哑光塑料/磨砂金属/玻璃通透/皮革纹理）
11. 构图单一焦点，信息层级 ≤3 层
12. 整套风格关键词统一（同一套 3~5 个 style lock 词贯穿全屏）
13. draft 探索 ≤3 轮，选定方向后切 final 档
14. 平台合规字段已编码进 Prompt（Amazon 白底/占比 85% 等，非事后修）

## 四、通用正向 Prompt 质量词（每条终稿必带）

```
commercial photography, studio quality, sharp focus, high detail,
realistic texture, professional color grading, clean composition,
natural shadows, 8K detail level, no AI artifacts, no plastic skin,
no oversaturated HDR, editorial e-commerce quality
```

**按方向追加**：
- 跨境 Listing：`lifestyle context, feature callout layout, magazine editorial grid`
- 国内详情页：`卖点可视化, 信息卡片层级清晰, 高级电商详情页质感`
- 社媒组图：先按任务分型；AI/Agent 功能发布使用 `interactive future AI product launch, visible input-feedback-orchestration-output causality, one decisive model-selected chromatic focal accent, crisp spatial depth, high-end commercial lighting, refined editorial typography`；**输出区必过** [`C4/references/commercial_output_evidence.md`](references/commercial_output_evidence.md)；**整组必过** [`C4/references/poster_grade_acceptance.md`](references/poster_grade_acceptance.md)（P1 封面五项 PASS）；只有普通内容种草才使用 `human-authentic creator note feel`

## 五、通用负面 Prompt（每条终稿必带）

```
blurry, low resolution, jpeg artifacts, oversharpened halos,
deformed product, wrong logo placement, stretched proportions,
extra parts, missing parts, floating objects, bad anatomy,
malformed hands, extra fingers, text gibberish, watermark,
cheap template look, cluttered layout, inconsistent style between frames,
overexposed, plastic skin, AI-generated look, cartoonish unless intended
```

## 六、产品保真 · Visual DNA 锚点（有 SKU 时必锁）

> 借鉴 product-shots 14-anchor identity lock，压缩为工作台通用版。

| 锚点 | 锁定内容 |
|------|---------|
| 产品造型 | 轮廓/比例/结构件数量与位置 |
| 包装 | 颜色/LOGO 位置/包装文字/图案 |
| 材质 | 哑光/高光/透明/织物纹理 |
| 色彩 | 产品本体色 + Brand Kit 推导色（非平台 VI） |
| 光影 | 全套统一光源方向与色温 |
| 镜头 | 同一套焦距感（35mm 生活 / 85mm 产品特写） |
| 模特（如有） | 族裔/年龄段/妆造风格全套一致，禁复刻参考图脸 |

跨屏/跨角度生成时，**同一锚点集注入每次请求**；③ 质检与第 0 步多角度参考集比对。

## 七、出图后质检（③ 品牌质检 Agent 追加项）

在 C2 合规基础上，增加**视觉质量三级判定**：

| 等级 | 条件 | 动作 |
|------|------|------|
| ⛔ REJECT | 产品变形/LOGO 位移/模糊到文字不可读/明显 AI 廉价感 | 打回 ② 重渲 |
| ⚠️ REVIEW | 轻微噪点/局部过曝/文字 OCR 1~2 字偏差 | 修订 Prompt 后重生，或走 C3 精修 |
| ✅ PASS | 清晰锐利/产品保真/与确认稿一致/风格统一 | 进 H2 |

**必查项**：清晰度（放大 200% 无块状模糊）、产品保真比对、全套风格一致性（色温/字体/卡片样式）、平台合规（Amazon 白底等）。

### 文字与语义硬拒绝

- 任何必需文字、页码、CTA、页脚被裁切、贴边或进入危险区：`REJECT`。
- 中文被压扁、拉伸、弯曲、镜像、刻在曲面或透过材质折射：`REJECT`。
- 软件/服务任务被误解成儿童积木、玩具、无关消费硬件或静态装饰人物：`REJECT`。
- 以抽象图标、图表、波形、线框或占位卡冒充可上线终稿：`REJECT`。
- 用户指定电影科技光效却呈灰雾低对比，或指定清爽交互 3D 人物却变成玩具/吉祥物：`REJECT`。

---

## 八、超分与修复（终稿交付前可选）

- 多次编辑变糊 → 走 C3「超高清增强」：仅提升分辨率/纹理，**人物与产品特征 100% 不变**
- 1K 终稿需 4K 延展（线下/大屏）→ 超分至长边 3840px+，再查锐化光晕
- 禁止：用超分「改设计」，只「提画质」
