## 为什么是方案 E（不是 A/B/C/D）

| 方案 | 数据精度 | 合规 | 成本 | 复杂度 | 选 |
|---|---|---|---|---|---|
| A：Slock 多智能体讨论 | 中 | ✅ | ❌ 高 token | 高 | ❌ |
| B：钉钉智能体单 agent | 中 | ✅ | 中 | 中 | 备用 |
| C：钉钉工作流 + Tavily | 中 | ✅ | 低 | 中 | 备用 |
| D：自建小红书爬虫 | 高 | ❌ 灰色 | 低 | 高 | ❌ |
| **E：人挑图 + AI 一次看** | **高（真图）** | **✅** | **极低** | **极低** | **✅** |

方案 E 把"调研"这件**人比 AI 强**的事还给人，把"看图判断 + 写文案"这件**AI 比人快**的事交给 AI。

## 推荐 AI 工具（任选其一）

### 1. 看图判断 + 出表（核心工具）

| 工具 | 一次能传几张图 | 推荐模型 | 推荐度 |
|---|---|---|---|
| Cursor 聊天 | 8-10 张 | Claude Opus 4.7 / GPT-5.5 | ⭐⭐⭐⭐⭐ |
| Claude Desktop | 20 张 | Claude Opus 4.7 | ⭐⭐⭐⭐⭐ |
| 钉钉智能体（多模态） | 4-9 张 | 千问 VL Max | ⭐⭐⭐⭐ |
| 通义千问 App | 9 张 | 千问 VL Max | ⭐⭐⭐ |

### 2. 拿表格里的 AI生图Prompt 去生图（配套工具）

把表格 `AI生图Prompt` 列的内容复制到下面任一工具：

| 生图工具 | Prompt 语种 | 单张成本 | 风格特点 | 推荐度 |
|---|---|---|---|---|
| **即梦 AI（字节）** | 中文/英文都行 | 免费/订阅 | 国风/小红书风强 | ⭐⭐⭐⭐⭐ |
| **可灵 AI（快手）** | 中文/英文 | 免费/订阅 | 真实感强、人像好 | ⭐⭐⭐⭐⭐ |
| **Midjourney** | 英文优先 | $10/月起 | 艺术感最强 | ⭐⭐⭐⭐⭐ |
| **FLUX（Black Forest Labs）** | 英文 | API 约¥0.5/张 | 真实质感顶 | ⭐⭐⭐⭐ |
| **通义万相（阿里）** | 中文/英文 | API 约¥0.5/张 | 中文场景准 | ⭐⭐⭐⭐ |
| **豆包 / Seedream** | 中文 | 免费 | 入门首选 | ⭐⭐⭐ |
| **Stable Diffusion** | 英文 | 本地免费 | 可控性强 | ⭐⭐⭐ |

**强烈推荐组合**：
- **国内日常**：钉钉智能体出表 + 即梦 AI 生图（成本最低、风格最贴小红书）
- **质量精修**：Cursor 出表 + Midjourney / FLUX 生图（出片质量最高）

> 表格默认输出英文 prompt（兼容所有工具）。如果你主要用即梦/可灵，可以让 AI 切换到中文 prompt，详见 [SOP-每周操作.md](./SOP-每周操作.md) Q4。

## 升级路线

| 版本 | 状态 | 描述 |
|---|---|---|
| **V1** | ✅ 已上线 | 方案 E 半自动 · 本地 Cursor / Claude Desktop（[SOP-每周操作.md](./SOP-每周操作.md)） |
| **V2** | ✅ 已配置 | 钉钉智能体「PLOG选题总监」（[钉钉智能体配置.md](./钉钉智能体配置.md)） |
| V3 | ⏳ 远期 | 接入千瓜/新榜数据 API，AI 全自动 |
| V4 | ⏳ 远期 | 定时自动跑 + 自动入表 + 自动通知设计师 |

**V1 vs V2 怎么选**：
- 个人精修 / 质量复核 → **V1（Cursor）**
- 团队日常 / 老板要看 → **V2（钉钉智能体）**
- 推荐：日常用 V2，遇到难判断的图用 V1 复核
