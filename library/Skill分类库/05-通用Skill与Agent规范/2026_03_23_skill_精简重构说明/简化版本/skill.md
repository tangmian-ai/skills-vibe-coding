# 小红书人像封面生成 Skill

## 1. Prompt 生成核心结构（Seedream 专用格式）

```text
(素人原生感),(真实日常场景),（生活化手机实拍质感）。
[海报主题]：[超精简概括，不超过10字]。
[人物维度]：[性别/着装] + [表情] + [手部/腿部动作] + [景别] + [拍摄角度]。
[背景维度]：[与主题相关的真实场景],适当虚化处理。
[装饰元素]：[所有装饰元素及其风格质感]。
[文案信息]：[主标题] + [副标题] + [辅助文案（若有）]。
[版式框架]：[顶部：主标题排布] + [中部：人物+辅助元素位置] + [底部：副标题排布]。
[字体样式]：[主标题：文案+字号+颜色+效果] + [副标题：同上] + [辅助文案：同上]。
[图层前后关系]：[从上到下排列]。
[整体风格]：日常实拍写实质感，高点击率社交媒体封面风格，高清晰度。
[画面比例]：3:4。
```

## 2. 交互流程

**第一阶段：文案确认**
- IF 用户明确指定了最终文案（含"主标题为：xxx"等确定性表述）→ 跳过，进入第二阶段
- ELSE 用户只给了宽泛主题 → 读取对应 `references/文案-{赛道}.md` + `references/违禁词.md`，生成 3 条不同风格的文案方案（主标题+副标题），询问用户选择。提示用户：确认后将直接生图。

**第二阶段：画面构建**
- 将确认文案映射到 Prompt 结构的 `[文案信息]`
- 读取命中的模式 reference + 人像赛道 reference + `references/prompt-公式.md`，填充完整 Prompt
- 直接调用 Seedream 4.5 模型生成图片（`aspect_ratio="3:4"`），生成后询问用户是否需要修改

## 3. 模式触发条件

| 模式 | 触发条件 | 读取 Reference |
|------|---------|---------------|
| A 同款复刻 | 2图（人物图+参考图）+ 文案 | `references/模式A-复刻.md` |
| B 博主定制 | 1图（人物图）+ 文案 | `references/模式B-定制.md` + `references/人像-{赛道}.md` |
| C 虚拟IP | 0图 + 文案 | `references/模式C-虚拟IP.md` + `references/人像-{赛道}.md` |

## 4. Reference 路由索引

**必读（每次）**：`references/prompt-公式.md`、`references/视觉标准.md`

**赛道路由**（根据用户主题匹配 1 个）：
- 职场/求职/办公 → `人像-职场.md` / `文案-职场.md`
- 学生/考试/校园 → `人像-校园.md` / `文案-校园.md`
- 运营/涨粉/自媒体 → `人像-自媒体.md` / `文案-自媒体.md`
- 其他（母婴/家居/旅行/美食/穿搭等） → `人像-通用生活.md` / `文案-通用生活.md`

**按需**：虚拟形象需求 → 额外读取 `references/人像-虚拟角色.md`

**模式 C 人像文件读取规则**（0图+文案时）：
- 若用户指定虚拟/卡通 → 读取 `人像-虚拟角色.md` + `人像-{赛道}.md`
- 若用户指定真实人像 → 读取 `人像-{赛道}.md`
- 默认 → 读取 `人像-虚拟角色.md`
