# 小红书文字PLOG 检索工具 使用说明

为钉钉「PLOG选题」智能体提供本周小红书检索结果。
跑完后输出一份 Markdown 文件，复制粘贴到智能体即可。

---

## 一、依赖

- Node.js ≥ 20（你本机 v22 已安装在 `../.slock-runtime/node-v22.22.2-darwin-x64/bin`）
- Tavily Search API Key（已配置在 `.env`）
- 不需要安装任何 npm 依赖（用 Node 原生 fetch + `--env-file` 加载环境变量）

---

## 二、首次确认

打开终端，进入工具目录：

```bash
cd "/Users/edy/Desktop/字体设计skill/字体设计skill_简化版/小红书搜索工具"
```

如果终端找不到 node，先把本地 node 临时加到 PATH：

```bash
export PATH="/Users/edy/Desktop/字体设计skill/字体设计skill_简化版/.slock-runtime/node-v22.22.2-darwin-x64/bin:$PATH"
node --version   # 应显示 v22.22.2
```

---

## 三、跑全部大主题（默认）

```bash
npm run search
```

会按 `关键词清单.json` 里所有 8 个大主题逐个检索。

输出：
- 终端会打印整份 Markdown
- 同步保存到 `outputs/搜索结果_YYYYMMDD_HHmm.md`

---

## 四、只跑某个大主题

```bash
npm run search -- 颜色+文字拼贴plog
```

或多选：

```bash
npm run search -- 颜色+文字拼贴plog 上下文字plog
```

匹配规则：模糊包含。例如 `npm run search -- 颜色` 也能命中「颜色+文字拼贴plog」。

查看所有可用大主题：

```bash
npm run search:list
```

---

## 五、改关键词

直接编辑 `关键词清单.json`：

- 加大主题：往 `大主题` 数组里追加一段
- 改检索词：改对应大主题下的 `queries` 数组
- 控制每条检索词的结果数：改顶部 `max_results_per_query`
- 检索深度：`search_depth` 可改为 `"advanced"`（更慢但更细，免费额度消耗更多）

无需修改 `search.js`。

---

## 六、把结果送进钉钉智能体

1. 打开 `outputs/搜索结果_xxx.md`
2. 复制全部内容
3. 粘贴到钉钉「PLOG选题」智能体的对话框
4. 智能体会基于检索结果展开 6-8 个小主题

文件末尾已经自动附了一段「给智能体的指令模板」，包含本期大主题，直接发即可。

---

## 七、Tavily 免费额度

- 1000 次检索 / 月（足够每周跑全部大主题数十次）
- 一次 `npm run search` 大约消耗 = 大主题数 × 该大主题下的 queries 数。
- 默认配置一次完整跑约 24 次（8 大主题 × 3 检索词）。
- 想省额度：减少 `queries` 数或只跑单个大主题。

## 八、常见问题

**Q：报错 `未读取到 TAVILY_API_KEY`**
A：确认 `.env` 文件存在且不是空的。务必用 `npm run search`，不要直接 `node search.js`，否则不会加载 `.env`。

**Q：报错 `Tavily 401`**
A：API Key 无效或被封。去 https://tavily.com 检查或重新生成。

**Q：报错 `Tavily 429`**
A：超出免费额度或频率限制，等下个月或升级套餐。

**Q：返回结果都不是小红书站内**
A：Tavily 是网页搜索，返回的是公开网页。小红书站内点赞/收藏/评论拿不到，只能拿到外部网页转载和讨论。第一阶段够用，后续要更准可以接专门的小红书数据服务。

**Q：API Key 安全吗**
A：`.env` 已被 `.gitignore` 排除，不会进入 git。如果你要把整个项目分享出去，记得不要附带 `.env`。
