# Prompt Framework

Use this order for the first production prompt:

```text
[Output and use] + [hero subject and must-preserve details] + [subject relationship]
+ [composition / camera / copy-safe area] + [scene and materials]
+ [art direction: palette, light, texture] + [constraints]
```

Example structure:

```text
Create a premium [ratio] campaign visual for [brand]. The hero subject is [subject]; preserve [details].
Composition: [camera, hierarchy, blank copy area]. Scene: [setting, props, material].
Art direction: [palette, lighting, texture]. Constraints: [what must not change / appear].
```

Do not ask the model to generate production-critical long text, price claims, legal copy, or a precise logo. Reserve these areas for Figma, Photoshop, or the approved design system.
