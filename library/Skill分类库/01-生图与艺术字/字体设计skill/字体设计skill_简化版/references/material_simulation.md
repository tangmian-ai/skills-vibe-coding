# 材质模拟 (Material Simulation)

适用：自然、手工、玻璃、水、毛绒、布料、木材、食物等

## 风格词库
- **流体与通透**：3D流体软管、透明玻璃材质、水流拼接、液体质感
- **织物与毛绒**：毛绒材质、摇粒绒、丝绸布料、棉麻布面料、牛仔布、刺绣效果、毛线钩织
- **自然与木材**：木材拼接字型、原木、胡桃木纹、沙子构成、植被覆盖
- **手工与食物**：黏土质感、面包、手工指纹

## 视觉要求
- **字形**：结构必须与材质物理特性结合（[水流] 形态、[藤蔓] 缠绕、[毛绒] 膨胀、[木材] 拼接）
- **材质**：精准描述物理属性 [折射]、[颗粒]、[纤维]、[蓬松]、[刺绣]、[木纹]、[焦散效果]
- **背景收敛**：水流/藤蔓/植被/烟雾/热气等元素必须收敛在文字轮廓内，严禁蔓延到背景区域
- **反悖论**：严禁物理属性冲突（水流材质禁出锐利折角，柔软布料禁出金属反光）

## 示例
- 流水液体：`字体设计"情人节"，完全由粉色流动的水拼接而成的手绘书法狂草体（有巧妙的连笔和漂亮的拖尾，这些由水构成，通透且自然）。纯黑色背景。`
- 木纹抽象：`艺术字 "原木"，呈现现代抽象字体的动感，采用胡桃木纹材质流体设计（造型如木纹肌理缠绕成流动漩涡，兼具木材温润感与装饰艺术精致感），极简纯白背景。`
- 花卉写实：`"Valentine's Day"字体设计，极度写实的生物拟态风格流畅连笔花体艺术字，文字由娇嫩的玫瑰花枝自然生长扭曲而成（连接处自然流畅，花瓣边缘轻微卷曲），渲染采用微距风格，纯黑色背景。`
- 毛绒3D：`黄色文字"招财"，可爱的3D字体设计，采用毛绒材质（文字表面都是毛茸茸的，细节丰富，突出绒毛细节），结合一个毛绒的元宝元素设计，纯白色背景。`
- 刺绣织物：`粉色"情人节快乐"字体设计，金色描边，花式字体（连笔变细，部分笔画末端连笔），文字采用刺绣效果（还原绣线纹理与立体凸起的刺绣质感，绣线含深浅纹理变化），纯黑色背景。`
- 面包食物：`"梦想"字样，采用面包做成的（面包呈金黄色，表面撒有细砂糖，上面冒着热气）。文字之间连接自然流畅，强调食物的造型和质感，纯黑色背景。`
