# Skill 01 · 社媒图文视觉

## 先判断任务类型

1. 有商品图：先识别品类、主色、材质、用法和保真约束，再规划各页不同的使用角度。
2. AI / Agent 新功能发布：切换为 `agent-launch-saas`。将产品识别为可输入、可响应、可编排并实时展开结果的互动型未来科技产品，用清爽但高能量的新品发布视觉解释能力，不套商品海报或生活方式种草模板。
3. 普通内容种草：再采用原生社媒叙事，但仍需保持系列视觉一致。

本次「社媒 IP 图文 AI Agent」属于第 2 类。产品本体是软件能力，不是耳机、手机或一套虚构硬件。机器人、数字角色或实体装置只能作为 H1 明确选择的 AI 具象化隐喻，不能被描述成待售产品，也不能取代“一句需求 → Agent 协同 → 真实成品输出”的能力证据。

### 当前任务的视觉权重

- 80% 发布级高级视觉：商业控光、材质精度、构图张力、字级设计、色彩能量与完整系列感。
- 20% 产品信息理解：让用户看懂 Agent 的输入、反馈、协同与成套产出。
- 「社媒原生感」仅用于约束尺寸、缩略图可读性和翻页节奏，不采用随拍、生活方式道具、手持镜头或创作者日常作为主视觉。

## H1 视觉契约（生图前必须输出）

视觉 Agent 在 H1 固定以下字段，再拆逐页 Prompt：

- `campaign_thesis`：一句话说明这套视觉要让用户相信什么。
- `visual_motif`：一个贯穿全套的视觉母题，例如「一句需求穿过内容引擎，转化为整套图文」。
- `campaign_palette`：有 VI 时导入；有商品时从商品推导；均无时依据 Brief 提案并由 H1 确认，禁止套平台品牌色。
- `type_system`：标题、说明、功能标签三级关系；只有 H0 明确给出页码时才可加入页码。
- `series_signature`：调用 C6 从 VI、商品、Brief、品类行为和文案结构中生成候选并评分，只选一个显性系列锚点。不得由方向模板预设，也不得同时把相同背景、相同主标题、相同构图和相同主视觉全部锁死。
- `series_invariants`：全套不变的材质、光线、圆角尺度与信息线；不得用页码或翻页数量冒充传播概念。
- `page_specs`：每页的传播任务、唯一主视觉、镜头/构图、准确文案和禁用元素。

## `agent-launch-saas` 艺术方向

目标是「未来感与科技感并存，但仍像清爽、可信、可使用的 SaaS 产品发布」，避免把科技感等同于暗黑电影棚。

| 维度 | 规则 |
|---|---|
| 画面基底 | 明度、冷暖和具体色相由 H1 根据 Brief/VI 决定；选一个主导有彩色族实际覆盖 Agent 核心、反馈路径与输出表面，允许受控相邻色或光谱反射。灰白只作承托，不能占据主视觉注意力；清爽不等于全灰、发白或低对比，不硬编码平台色或默认蓝青 |
| 视觉材质 | 由 H1 选定原型决定：可使用精密透明材质、磨砂金属、真实屏幕、电影光场、纸张/印刷、技术线稿或高级 CGI 人物；不得固定成玻璃系统，统一要求真实光影、边缘完整与拒绝廉价塑料感 |
| 核心母题 | Brief 输入激活 → Agent 实时反馈 → 策略/文案/视觉信号协同 → 多张社媒图文展开；必须一眼看懂“互动、编排与结果”，不能只画静态流程图、抽象宇宙或 AI 大脑 |
| 信息层级 | 小号发布标签 → 7–9 字核心命题 → 常规字重能力说明 → 分层能力词 → 单一产品能力主视觉；依靠字级、字宽、方向和留白建立关系，不靠单纯放大 |
| 构图 | 3:4 竖版；左右 8%、顶部 12%、底部 16% 为文字安全区；主标题位于上方 12–30%，可居中、偏置或与主视觉穿插；主视觉占中部 30–76%；标签、CTA 与仅在 H0 明确要求时的页码均完整留在 76–84% 安全带 |
| 字体 | 现代无衬线为主体，用 Medium / ExtraBold / Regular / Light 四级字重建立层级。中文不临时混入宋体；如需第二字体，仅允许固定的英文展示角色（窄体、斜体或高对比衬线），并至少跨 2 页重复。主标题控制在 7–9 字、画布宽度 68%–76%，比普通社媒大字报缩小约 20%；仅 1 个关键词使用活动强调色 |
| 界面 | 只展示与功能有关的真实结构：输入框、编排节点、6 图结果；界面文字少而准确，避免虚构完整软件或密集乱码 |

## 发布海报视觉原型库（由 H1 自主选择）

以下原型来自科技发布、开发者活动与产品功能海报的共同语法。H1 必须依据 Brief 的产品属性、传播目标与品牌气质选择一个主原型，也可吸收另一个原型的一项辅助特征；不得把五种风格混成一张图。

| 原型 | 标题排版 | 主视觉 | 配色与质感 | 适用条件 |
|---|---|---|---|---|
| `physical-ai-specimen` | 上部居中双层标题；中文粗无衬线 + 细英文说明；工程标记围绕主视觉 | 半透明/X-ray AI 机器人、智能终端或精密装置，辅以结构剖面和技术注释 | 黑底 + 单一高饱和荧光色 + 银白透明材质；高反差、硬朗、锐利 | Brief 强调 AI、智能体、机器人、开发者大会或技术突破，且品牌允许强科技发布感 |
| `spectral-developer` | 超大现代无衬线主标题居中；中英可分层；括号、斜杠或代码符号只作一次结构强调 | 一个大尺度抽象但可识别的开发者/网络符号，不使用小图标阵列 | 黑底 + 受控光谱渐变；色彩集中在一个主图形和少量标记 | 开发者活动、创意赛、生态发布；重点在事件身份而非功能教程 |
| `high-key-editorial` | 标题可偏置或居中；大留白；中等尺度中文标题配细英文基线；不扭曲中文字形 | 人物/空间/楼梯/路径等真实或超现实场景，使用单一光线动势 | 高键白/冰蓝/雾蓝 + 少量暖黄光；保留暗部与清晰边缘，拒绝灰白糊成一片 | 清爽 SaaS、新功能发布、记忆/记录/创作类产品 |
| `procedural-saas` | 标题与步骤信息分层；Step 编号、搜索框或输入框可成为结构节点 | 真实工作流、输入动作、Agent 响应和成品结果；以流程证据而非图标解释能力 | 浅蓝、白与品牌强调色；纸张/界面/磨砂材质，信息清楚可读 | 教程、使用流程、能力解释页，尤其适合 P2/P3/P5 |
| `schematic-update` | 超大压缩中文标题占上半屏，辅以小日期、版本和短说明；标题可与线框结构压叠一次 | 产品/功能的技术线框、剖面、数据轨迹或真实装置 | 黑底 + 琥珀/金色单色高光；工程图、坐标与细线刻度 | 功能更新、内测、版本发布；需要强冲击而不是清爽生活感 |
| `cinematic-light-field` | 中等尺度标题与细副标题形成仪式化锁定式，不用满屏巨字 | Agent 装置或软件因果路径置于体积光、光幕、反射空间中，成品终稿在光场末端展开 | 深色或浓郁色域 + 单一饱和光效；控制黑位、雾量和高光溢出 | 用户明确要求电影质感、科技光效或品牌需要发布片氛围 |
| `interactive-3d-agent` | 清爽编辑型字组与人物动作错位一次，副标题保持常规无衬线 | 精致成年 3D 人物/Agent 主动输入、拖拽、协调或展开真实终稿 | 高键空间 + 一个鲜明有彩族；真实接触阴影、布料与皮肤材质 | 用户明确要求清爽交互 3D 人物，或产品需要降低抽象理解成本 |

### 原型选择约束

- 当前 Brief 若强调「清爽 SaaS、可使用、低抽卡率」，优先在 `high-key-editorial` 与 `procedural-saas` 中选择；只有 Brief 或品牌证据支持时才转向黑底大会型原型。
- 机器人不是默认 AI 符号。只有当它能作为“响应、协作、执行”的 Agent 化身，并且画面仍展示真实产出证据时才可使用；禁止机器人、机械臂或芯片仅作为空洞科技装饰。
- 原型只决定视觉语法，不决定系列显性联系。显性联系仍由 H1/C6 从 Brief 中评分选择。
- 参考图中的第三方 Logo、平台角标、活动名称和搜索框品牌均不可进入生成结果。

## 版式语法

高级感来自稳定网格上的「受控张力」，不是一味居中或放大。六页从以下骨架中按传播任务选择，禁止连续两页使用同一骨架：

1. `centered-lockup`：短主标题居中，仅在内容本身适合仪式感时使用；标题不超过画面高度 24%。
2. `type-image-interlock`：文字与能力主视觉发生一次穿插或遮挡，适合 P3 能力解释。
3. `asymmetric-editorial`：偏置主标题 + 细信息列 + 大留白，适合 P2 痛点与 P6 CTA。
4. `capability-cloud`：关键词按 3 级字号/透明度围绕一个核心能力，不使用等权胶囊，适合 P3/P5。
5. `modular-grid`：字体、色彩、比例与成品图按严格网格对齐，适合 P4 Brand Kit。
6. `conference-center-stack`：小号发布标签 + 两层居中主标题 + 细英文基线 + 单一实体主视觉，适合有明确技术事件感的 P1；禁止把所有页都做成大会海报。

每页只允许一个主要张力手法：错位、压叠、纵排、跨栏或中英基线穿插五选一；其余元素回到网格。中文字符间距保持正常，避免为了“高级”强行拉开。

## 组图一致性

组图需要「一个强共同点 + 六个不同价值」，而不是六张复制品。

- H1 只锁一个显性的 `series_signature`。本项目可候选「信息光路」「输入到结果的图形路径」「清爽高键摄影语言」等，但必须由模型根据 Brief 证据与可延展性评分后推荐，再由 H1 确认。
- 字体角色、网格、安全区、材质精度属于隐性系统约束，用于维持品质，不应让六张看起来像同一模板。
- 每页必须有独立 `audience_value`，标题、主视觉和版式都服务于该页价值，不能只换背景或只换文案。
- 相邻两页不得同时复用相同版式骨架、相同主视觉镜头和相同信息密度。
- 六页价值默认拆分为：P1 一句话成套出图；P2 节省重复劳动；P3 策略/文案/视觉协同；P4 IP 与品牌一致；P5 多体裁多尺寸适配；P6 带字终稿可直接交付。

## 六页叙事

| 页 | 传播任务 | 画面任务 |
|---|---|---|
| P1 封面 Hook | 建立新品类认知 | 默认采用非对称动态字组：小号发布标签建立起点，7–9 字产品命题以 2–3 个字级组织并与能力主视觉发生一次轻微穿插，常规字重副标题承接；能力词围绕一句话 Brief → Agent 内容引擎 → 6 张图文结果形成三层信息场。只有 H1 明确选择时才使用纯居中锁定式 |
| P2 说需求 | 呈现工作前痛点 | 把选题、写文、排版、反复修改压缩为清晰的问题链，不使用杂乱桌面隐喻 |
| P3 能力展示 | 解释产品如何工作 | 以真实工作台结构表现策略、文案、视觉协同，突出从输入到整套结果的路径 |
| P4 品牌一致 | 证明审美可控 | 展示色彩、字体、版式与图像语言如何汇聚成 Brand Kit，不做装饰性卡片墙 |
| P5 多面魅力 | 说明适配能力 | 以 3:4 / 1:1 / 9:16 成果和不同内容体裁建立可扩展性，所有小图仍属于同一视觉系统 |
| P6 CTA | 收束行动 | 简洁展示输入需求与生成结果，保留明确 CTA，不突然切换成深色广告片或人物摄影 |

## 生产流程

1. 策略 Agent 产出文案，并在 H0 锁定为下游唯一文字源。
2. 视觉 Agent 先生成 H1 视觉契约，再为每页生成独立 Prompt；禁止六页只换标题。
3. 封面以 review 档单独生成并确认母题、色板、字级和材质，再扩展其余页面。
4. **S01 Agent 功能推广默认链路**：图像模型生成无字场景（消费 H0 `layout_note`）→ **C5 Skill 路由 `TypographySpec`** → 程序艺术字引擎合成（渐变/描边/投影/动态字级/能力字场）→ **一次导出完整带字终稿**。
5. 其他方向或需探索时，仍可使用模型直出带字；H2 导出以 OCR 通过的终稿为准。
6. 质检失败时按单项返修：文字错误只修文字，界面漂移只修界面，构图问题只调整构图；不要每次推翻整张图重新抽卡。

## 封面验收

> **海报级合格线**：单页至少满足 [`C4/references/poster_grade_acceptance.md`](C4/references/poster_grade_acceptance.md) 五项 PASS；**P1 不达标 = 整组不合格**。对标科技活动 KV（粗体 Display 字、 intentional 网格、主视觉材质完成度、≥30% 主导色、真实商业海报终稿证据）。

- 3 秒内能回答：发布的是什么、解决什么问题、最终产出是什么。
- 主标题逐字正确；不能被主视觉遮挡，不能靠白色描边或重阴影补救可读性。
- 主视觉是「Agent 内容生产能力」，不是硬件商品、机器人、AI 大脑、太空舱或抽象光球。
- 若 H1 选择 `physical-ai-specimen`，机器人只能是 Agent 的视觉化执行者；标题、输入信号和真实商业成品输出必须共同证明软件能力，不能变成机器人产品广告。
- 任何表示“输出结果”的卡片都必须像可发布的真实电商图/社媒海报：含摄影主体、场景、光影与完整版式层级。禁止扁平图标、抽象圆形、图表、线框或占位卡充当终稿；作为大海报内的缩略图时，以画面主体和构图证明“终稿”，缩略图内部不得出现任何可读小字、虚构标题、商品卖点、平台标识或 UI 标签。
- 功能说明不超过 3 组；装饰元素不超过 2 类；缩略图仍能读出主标题。
- 色彩、光影和材质达到软件新品发布水准，同时与真实工作台的清爽气质一致。
- 缩略图中必须存在一个明确有彩焦点、一次动态反馈和一个可辨识的输出结果；不能只有灰白材质与静态说明。
- 有彩色不能只是一处按钮、文字或小点缀；它必须参与主视觉主体与互动路径，形成足够的缩略图色彩面积。

### 三种艺术方向边界

- 原始需求：H1 自主选择证据最强的海报原型、色调与系列锚点，不把 AI 固定为蓝青玻璃。
- 用户追加「电影质感科技光效」：以受控黑位、饱和光效、电影级前中后景和精密材质为边界，禁止灰雾赛博与廉价游戏霓虹。
- 用户追加「清爽交互 3D 人物」：精致成年角色必须实际接收需求、反馈或展开终稿，禁止儿童、玩具比例、吉祥物、塑料办公头像和静态站台。
- 机器人或人物不是禁用项，也不是默认项；只有承担软件因果动作时才可成为主视觉。

### 终稿证据与文字硬门槛

- 任何表示「生成结果」的缩略图或输出墙，必须像**设计师交付的无字画面层**：摄影/渲染主体 + 商业布光 + 版式分区，对标美图 Banner / 电商 KV 下刊质量。**完整 Skill**：[`C4/references/commercial_output_evidence.md`](C4/references/commercial_output_evidence.md)
- **竞品合格线**（工作台必须超越模板库）：[`C4/references/competitive_benchmark.md`](C4/references/competitive_benchmark.md) — 美图 App Banner + 小红书信息图组图
- **必 REJECT 的 AI 半成品**：拍立得白框、色板条、抽象空镜（山/水/花/丝绸）、perforated hub + 虚线流程图、线框占位卡、统一 AI 蓝灰 mood board。
- 抽象图标、圆形、波形、图表、线框、空白卡片、儿童积木不能代替终稿。
- 左右 8%、顶部 12%、底部 16% 为不可侵入安全区；主标题高度通常不超过画布 18%。
- 字数过长时缩小字号、重断行或调整字组，不删字、不压缩、不拉伸、不弯曲、不刻在玻璃/圆环/曲面上。
- 任一必需字、页码、CTA 或页脚被裁切、贴边、关键笔画粘连，C2/C4 直接 REJECT。
- H0 封闭文字集适用于整张图：只允许 H0 标题、正文、卖点、标签与 CTA；所有屏幕、卡片、缩略图和输出墙均不得生成可读文字、页码、日期或 UI 标签。需要终稿证据时使用无文字、摄影导向的成品画面。

## 必禁

- 暗黑电影棚、星空宇宙、赛博城市、强紫色霓虹作为默认科技表达。
