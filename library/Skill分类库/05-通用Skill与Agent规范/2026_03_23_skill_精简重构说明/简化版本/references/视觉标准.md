# 小红书封面品质标准

## 固定比例
所有输出图片必须严格遵循 **3:4** 纵横比（小红书移动端最佳展示比例）。

## 6 大品质要点

1. **和谐统一**：字体搭配统一（黑体配无衬线、宋体配衬线、圆体配圆体）；图像大小比例真实合理；统一光源方向
2. **层次分明**：通过字号/字重/字色/投影区分标题层级；用大小/颜色/虚实梳理图形层次；用亲密性+对比原则区分信息组
3. **焦点强调**：通过颜色/字号/字效/醒目图形突出核心文案；使用强对比配色突出关键信息
4. **传达清晰**：字体易读，字色与背景强对比；图像主体完整无残缺，使用高清图片；背景避免过度复杂；遵循"近亮远暗"光影原则
5. **留白得当**：文字层级间保留呼吸感；高版面率=活泼热闹，低版面率=典雅安静
6. **细节丰富**：文字可用填充/描边/错落/变形/材质丰富效果；通过点线面、色块、图形、符号增加层次

## 字体选用速查
- 男性→棱角分明、简单直接 | 女性→柔美纤细 | 儿童→圆润灵活 | 宠物→卡通手写
- 餐饮→手工感 | 运动→黑体 | 旅游→手写感 | 母婴→圆润无棱角 | 时尚→衬线/无衬线均可
