# 通用/生活赛道人像特征

适用：母婴、家居、旅行、地产、美食、穿搭、金融、健身、彩妆及其他未列出的场景。

根据用户主题匹配对应子类特征：

- **母婴**：亲子互动场景，表情微笑柔和，宝宝为画面焦点
- **家居**：人像自然融入家居空间，展现分享新家的喜悦，与家居物品互动
- **旅行**：各种旅行场景，惊喜/兴奋/享受表情，自然旅行动作，生活化穿搭
- **地产**：楼盘/户型场景，着装职业化，指向/引导动作，亲和专业神态
- **美食**：夸张/惊喜/享受表情，与美食互动，拿取/品尝/指向动作，造型偏日常
- **穿搭**：休闲/街头/日系/潮流风格，日常出街/职场/运动场景，全身搭配，自然站立行走
- **金融**：专注认真沉稳表情，手势辅助阐述，书房/办公室场景，正装或简约得体
- **健身**：健身房/户外训练场地，引体向上/举铁/拉伸动作，自信力量感，运动服装备
- **彩妆**：脸部特写突出妆容，日常妆/创意妆/仿妆，妆前妆后对比，指向镜头手势
