# 创意装饰 (Creative Decoration)

适用：涂鸦、POP、故障、像素、拼贴、光影特效

## 风格词库
- **涂鸦与POP**：街头涂鸦、潮流涂鸦、马克笔POP字、卡通字
- **复古与像素**：像素字、复古像素游戏标题、复古美术字体、美式复古、哥特体、花体字
- **拼贴与组合**：立体折纸、层叠剪纸、撕纸字体、图形字、食物组合字
- **特效与光影**：故障字、血液效果、消散、拖拽光影、弥散、粒子效果

## 视觉要求
- **字形与效果（按语境选用）**：
  - 涂鸦/POP/童趣语境 → [毛毛虫挤压]、马克笔质感、卡通线条，装饰用星星/爱心/箭头，严禁暗黑/血腥/故障
  - 复古/像素语境 → [方块像素]、像素颗粒、复古印刷纹理
  - 拼贴/手工语境 → [纸艺拼贴]、折痕纹理、撕纸边缘
  - 特效/暗黑语境（故障/血液/消散等）→ [信号错位]、[流星轨迹]、RGB色散、粒子消散，仅用户明确要求时使用
- **装饰**：装饰元素须与笔画深度融合
- **背景收敛**：喷漆颗粒/RGB色散/光影拖拽/消散粒子等特效必须收敛在文字主体附近，严禁大面积扩散到背景
- **反悖论**：严禁古风、禅意等静谧风格描述

## 示例
- 涂鸦街头：`干净的纯黑色背景。平面艺术字体设计"燥起来"（街头涂鸦风格，笔画粗犷夸张，如同马克笔快速书写的痕迹，边缘带有流淌效果）（荧光绿填充，带有紫色粗描边）。装饰喷漆颗粒与箭头符号融入笔画末端，风格完全统一。比例4:3`
- 像素方块：`内容为"小夕宝贝"的游戏LOGO设计，采用像素风格字体，笔划呈现方块像素画结构（整体进行抽象变形，边缘自然阶梯状），纯黑色背景。`
- 立体折纸：`白色的字体设计"纸艺春节"，用立体的折纸艺术呈现（站立的折纸字），纯黑色背景。`
- 故障失真：`文字"立即关机"，采用故障艺术风格呈现（条纹因信号干扰发生扭曲、错位与倾斜，边缘自然溢出蓝、紫、红的RGB通道分离色散；模拟电子数据故障的视觉失真）。无衬线体小字装饰性文案"下班放假 请勿打扰"作为点缀，纯黑色背景。`
- 拖拽光影：`"夏日重启时"，抽象变形的创意字体，笔画渐隐（线条流畅富有动感，尾部光影拖拽），纯黑色背景。`
