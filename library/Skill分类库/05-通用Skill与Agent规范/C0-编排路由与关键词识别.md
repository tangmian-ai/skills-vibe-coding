# Skill C0 · 编排路由与关键词识别

> 解决：用户选了「跨境电商」或在输入里写「亚马逊」，但策略 Agent 仍输出中文的问题。
> 本 Skill 在编排层**先于** ① 策略 Agent 运行，产出 `routing_context` 注入下游。

## H-1 产品理解门槛（上传商品图时必跑）

在路由完成后、策略 Agent 前运行 Product Vision。它不只识别“是什么”，还要输出：

- `category_path`：一级品类 > 二级品类，例如 `食品饮料 > 烘焙零食`、`服装鞋包 > 女装连衣裙`
- `visual_features`、`main_colors`、`material_finish`
- `usage_scenarios`：3~5 个可视化的真实使用/购买场景
- `avoid` 与 `uncertainties`：图片无法证明的功效、参数、成分、尺寸、认证等

工作台必须显示可编辑的确认卡。只有 `product_context.confirmed=true`，策略 Agent 才能把品类和使用场景写进文案；`avoid` / `uncertainties` 中的内容不能被包装成卖点。具体品类优先于包装形态，例如“曲奇礼盒”按食品场景，而不是泛化为礼盒模板。

## 识别优先级

1. **物料方向下拉**（用户显式选择，权重最高）
2. **用户输入关键词**（补充/覆盖平台与市场，不覆盖已选方向大类）
3. **默认值**（社媒图文 → 中文 / 社媒通用；**仅当 Brief 写出平台关键词时才绑定具体平台**）

## 文案平台名规则（H0 必守）

- `routing.platform` 是内部尺寸/渠道参考，**不等于可写入 H0 的平台品牌名**
- 用户 Brief **未**出现小红书/抖音/微博等平台词 → 策略 Agent 的 title/body/tag/benefits **禁止**出现任何平台名
- 仅当 Brief **明确写出**某平台时，才可在文案中使用该平台名（仍禁止画成产品 Logo）

## 节日模板 · 商品模式判定（编排层必跑）

`resolveProductMode()`（`tools/product_mode.mjs`）在 **S02 节日模板** 下强制三选一：

| 模式 | 条件 | 编排行为 |
|------|------|---------|
| **pure_festival** | 无上传 + Brief 无产品词 | 纯节日空镜；禁耳机预制批次；C5 艺术字 |
| **product_with_image** | 已上传商品图 | 保真链路；读图质量差 → C3 精修建议 |
| **product_brief_only** | Brief 有产品词、无上传 | 品类推演；质检 REVIEW；提示补传图 |

详见 [`物料方向与场景说明.md`](物料方向与场景说明.md)。

## 市场覆盖关键词

输入中出现以下词时，覆盖 `target_market` 并可能调整语言：

- 美国 / US / USA → US, English
- 日本 / JP / 日本站 → JP, Japanese
- 德国 / DE / 欧盟 → DE/EU, English 或 German（输入含「德语」时）
- 东南亚 / SEA → Southeast Asia, English

## 输出：`routing_context`（注入 ① 策略 Agent）

```yaml
routing_context:
  direction: "跨境电商"           # 来自下拉
  skill: "04-跨境电商视觉"
  platform: "Amazon"
  target_market: "US"
  output_language: "English"       # 策略 Agent 文案包必须使用该语言
  matched_keywords: ["亚马逊", "Amazon"]  # 命中词，便于编排层消息展示
  locale_rules:
    - "All page titles, subtitles, CTA, hashtags in English"
    - "No Chinese in copy unless output_language is 简体中文"
    - "Amazon: no superlatives without evidence; inch/lb units in specs"
```

## design-assistant 挂载（RedSkill · 条件）

编排层在 strategy 之前调用 `tools/design_assistant_router.mjs`：

| 条件 | 行为 |
|------|------|
| `designer_mode=true` | 挂载 `skills/design-assistant/SKILL.md`，先阶段一～四再进自动 pipeline |
| Brief 过短 / 设计类型不明 | 工作台提示「建议设计师模式」；可继续自动或切换 |
| Brief 完整 | 直接自动 pipeline · **C5 一体艺术字生图**（不依赖 PingFang overlay） |

灵感词库可引用 `design-assistant/style-library.md`；竞品线见 `C4/references/competitive_benchmark.md`。
