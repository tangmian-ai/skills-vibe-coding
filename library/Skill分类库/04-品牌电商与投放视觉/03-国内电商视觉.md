# Skill 03 · 国内电商视觉

## 尺寸库
| 物料 | 尺寸 | 要点 |
|------|------|------|
| 商品主图 | 800×800（1:1，支持放大镜需 ≥800px） | 产品占比 ≥ 60%；首图禁牛皮癣（促销标签堆叠会被平台判低质） |
| 主图视频封面 | 1:1 / 3:4 | 第 1 帧即卖点 |
| 详情页 | 750 宽长图分模块 | 卖点 → 参数 → 场景 → 对比/信任 → 售后 |
| 直通车/引力魔方 | 800×800 / 平台指定 | 点击率导向：大字卖点 + 单一焦点 |
| 大促氛围图 | 按会场规范 | 618/双11 需跟平台官方色系与坑位模板 |

## 平台调性差异
- **天猫/淘宝**：品质感与营销感平衡，大促期允许强促销氛围
- **京东**：更干净理性，科技/家电类目重参数可视化
- **拼多多**：价格感知优先，直给型大字报（但仍禁虚假比价）
- **抖音电商**：内容化封面，像"短视频截图"而非"商品图"

## 产品呈现规则
- 产品包装必须用真实素材（抠图/图生图增强），禁止 AI 虚构包装与标签
- 同一 SKU 全套物料模特/场景一致（恒定参考图注入）
- AI 负责背景/光影/氛围，产品本体保真

## 6 屏基础画面结构（按品类替换，不照搬耳机）
| 页 | 通用任务 | 画面结构示例 |
|----|----------|--------------|
| P1 首屏 | 第一眼抓住利益点 | 深/浅品牌渐变 + 大产品 Hero + 大字核心卖点 |
| P2 卖点合集 | 多卖点快速扫读 | 2×2 卡片式卖点合集，每点配独立小示意图 |
| P3 原理/效果 | 把卖点视觉化 | 香水=喷雾/香调扩散；耳机=蓝牙/续航/音质波纹；护肤=成分切片 |
| P4 细节结构 | 证明做工品质 | 微距特写：接口/按键/耳罩/瓶盖/喷头/材质纹理 |
| P5 使用体验 | 真人或交付场景 | 佩戴、喷洒、手部交付、礼赠、通勤/办公/居家 |
| P6 规格收口 | 打消最后疑问 | 参数/服务/权益/CTA，清晰结构化，不再重复场景图 |

> 以上是平台转化逻辑，不是耳机模板。进入生成前必须做 product-read：识别商品品类、结构、颜色、材质、包装/标签、核心使用方式，并据此替换每屏画面。香水可出现喷洒、香气扩散、瓶盖喷头微距、礼赠交付；耳机可出现佩戴、连接、按键接口、场景佩戴；其他品类按真实使用链路改写。默认每屏一个主产品实例，除非 P2 卖点合集、P5 多场景或 P6 配件/规格页需要多个分区。

## 详情页生产 SOP（四步工序 · 淘系版 · 来自内部实操沉淀）

> 适用：8 屏（3:4 竖屏）高转化详情页 / 微详情。与跨境版（Skill 04）同源工序，
> 核心差异：中文文案与淘系人群标签、店铺定位驱动。流程映射标注在每步末尾。

### 第 0 步 · 产品多角度提取（素材预处理）
上传产品图，先生成多角度合集（正面/侧面/背面/仰视/俯视/细节，合成一张图），
作为后续所有出图的产品保真参考。
→ 对应：② 设计 Agent 素材预处理。

### 第 1 步 · 视觉风格体系定调
基于产品图联网检索同品类国内详情页爆款风格，反推产品专属【视觉风格体系】，
**固定六大模块输出**：
`整体调性 / 画面质感 / 布光逻辑 / 色彩体系 / 字体规范 / 构图规范`
- 贴合国内电商爆款逻辑：避免纯色背景，主打场景共情、卖点可视化
- 文案格式统一：字体类型统一、字号/字重层级分明、行距舒适
→ 对应：② 视觉方向提案 → **H1 确认**（六大模块即确认清单）。

### 第 2 步 · 淘系视觉诊断报告（双模式）
角色「资深淘系电商产品经理 & 视觉营销专家」，输入
**类目/赛道 + 店铺类型与定位 + 产品图**，输出【天猫/淘宝产品视觉诊断报告】。

**模式 A · 自动提取卖点**：AI 从包装文案/认证标识/产品形态自动挖掘
**模式 B · 用户输入卖点**：用户给定核心卖点，AI 做「卖点视觉翻译」——
每个卖点给出具体画面呈现方案（例：卖点"24h 保温" → "冰块与热气对比 3D 渲染 + 温度刻度流光"）

报告核心字段（相对跨境版的本土化差异）：
- **淘系八大策略人群**归属（资深中产/精致妈妈/新锐白领/GenZ/小镇青年/都市银发…）
- **黄金 3 秒主图文案**：字数精简、直击痛点的首屏利益点
- 痛点场景（熬夜修护/办公室久坐/精致露营/独居平替）
- 卖点分层：吸睛文案 / 成分工艺背书 / 功效数据认证 / 场景痛点 / 情感溢价与性价比
- 色彩规划（HEX 直接进 Brand Kit）/ 推荐视觉风格 / 文字排版建议 / 店铺定位
→ 对应：① 策略 Agent 的 Brief；双模式 = 工作台「有无现成卖点」两条入口；
　 卖点与宣称进 **H0 人工确认**（国标依据/比价用语在此拦截）。

### 第 3 步 · 8 屏分屏提示词方案
基于【视觉风格体系】+【诊断报告】生成 8 屏（3:4）分屏方案，每屏结构：
- 分屏功能标签（首屏吸睛/成分切片/场景共鸣/权威背书…）+ 视觉策划逻辑（本屏转化什么心理）
- 主标题 + 副标题（**简体中文**，黄金 3 秒爆发力）+ 排版形式
- 中文详细画面描述 + **英文正向 Prompt + 英文负面 Prompt**（尾带 `--ar 3:4`）
- **产品保真硬约束**（每屏英文 Prompt 必带）：
  `"Strictly replicate the product from the uploaded image, including the exact shape, color, logo placement, text engraving, and material textures without any distortion."` + 1:1 物理比例
- 卖点强视觉化：拒绝单纯摆产品，用科学切片 / 3D 解构 / 场景对比呈现
- 模特按淘系人群指定（新锐白领 → 清冷高智感东亚模特；国潮 → 中式面孔）
- 负面词必含：变形、低画质、多余牛皮癣、假标签
→ 对应：② 生成计划（image_plan）；可回 H1 抽查。

### 第 4 步 · 逐屏出图（防变形控制）
按屏独立调用图像模型（image-2 类），比例锁定 3:4，并：
- 挂载原始产品图/三视图作 **Image-to-Image / ControlNet 控形基准**
- 切换视角与场景时产品轮廓/工业结构/LOGO/刻印必须与参考图一致
→ 对应：② 批量生产 → ③ 质检（与多角度参考集保真比对 + 牛皮癣/假标签检查）→ H2 终审。

### 变体 · 风格复刻版（有参考图时）
用户提供竞品/参考详情页时，走 **C3-参考图反推与风格复刻**：
参考图反推风格 + 本 Skill 诊断报告 → **10 屏 2:3 竖屏**复刻方案。
红线：只学风格排版色调，禁抄参考图文字与模特长相，负面词加"不要指定人物族裔"。

### 变体 · 风格复刻版（有参考图时）
用户提供竞品/参考详情页时，走 **C3-参考图反推与风格复刻**：
参考图反推风格 + 本 Skill 诊断报告 → **10 屏 2:3 竖屏**复刻方案。
红线：只学风格排版色调，禁抄参考图文字与模特长相，负面词加"不要指定人物族裔"。

### 文字渲染策略
主/副标题、卖点与 CTA 均以 H0 确认稿直接进入生图 Prompt，成图后由 ③ 质检 **OCR 逐字比对**；不一致即修订 Prompt 并重生。

价格、划线价、优惠券、参数和认证只允许使用用户确认且有依据的信息；无依据时禁止生成，不能用默认文案补全。

## 强制核对（H0 节点）
- 价格 / 划线价 / 优惠券 / 库存 / 活动时间：必须客户确认版
- "0糖0卡""纯天然"等宣称必须有国标依据；比价用语禁"全网最低"
- 诊断报告中的卖点文案（黄金 3 秒稿）在此一次性确认

## 风格 preset
minimal（美妆/3C）· cozy（食品/母婴）· luxury（高客单）· bold（大促）
