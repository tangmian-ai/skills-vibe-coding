# 字体设计 Skill

## 1. Prompt 生成核心结构

```text
[干净的纯{色}背景]。
[维度：3D艺术字体设计 / 平面艺术字体设计]，[字数+"主体文字"]，所有文字单行横向排列（用户指定排列方式时除外）（[字形设计：具体笔画变形描述]）（[材质/色彩：主体色+描边色+装饰色]）。
仅包含N个字："X"、"X"、"X"...，不得增加、遗漏或替换任何一个字。
[副标/装饰设计（若有）]。
比例[宽:高]。
```

## 2. 模式判断与交互流程

**Step 0：提取用户显式需求（所有模式必须先执行）**
- 扫描用户输入，提取已明确指定的参数：背景色、维度、排列方式、比例、色彩、留白/构图比例等
- **已指定参数 → 锁定，后续步骤不可覆盖或修改**
- 仅未指定的参数才进入自动推导

**模式判断**：
- IF 用户上传了字体/风格参考图 → **仿图模式 (A)**
- ELSE → **文生模式 (B)**

### A. 仿图模式（参考图 + 新文案）

1. 分析参考图，提取：维度（3D/平面）、字形（笔画形态/变形手法/连接方式）、材质/色彩（主体色/描边色/装饰色）、背景、装饰元素
2. 将提取特征映射到 §1 Prompt 结构，文字替换为用户新文案；**Step 0 锁定的参数直接写入，不被参考图覆盖**
3. IF 用户要求调整部分风格（如"换个颜色""改成3D"）→ 仅修改指定维度，其余保持参考图风格
4. Prompt 构建完成后，调用「图片生成」skill，优先选择「seedream-4-5」

### B. 文生模式（文案 + 风格描述）

1. 风格推导（纯推理）：分析用户文案语义 → 匹配设计氛围（见§3）
   - IF 用户明确指定风格/材质 → 直接使用
   - ELSE 触发推导链：语义分析 → 氛围匹配 → 技法选择 → 参数补全
     - 例："龙" → 东方/霸气 → 东方美学 → 书法飞白/龙鳞纹理 → 黑金/纯白背景
   - IF 用户强制要求风格悖论（如"赛博宋体"）→ 执行融合：骨架重塑 + 材质置换 + 光影统一
2. 读取命中氛围的 Reference 文件（见§4）→ 按 §1 Prompt 结构填充；**Step 0 锁定的参数直接写入，不被推导结果覆盖**
3. Prompt 构建完成后，调用「图片生成」skill，优先选择「seedream-4-5」

**两种模式共同**：仅输出 Prompt，不附带分析文字

## 4. 核心规则

| 规则 | 要求 |
|------|------|
| 文字精准 | 逐字拆解 `仅包含N个字："X"、"X"...` + 字数前置（如 `四个字"新春大吉"`）+ 禁止衍生，一字不多一字不少 |
| 结构分隔 | 句号 `。` 分隔各模块，标准顺序：`背景。维度+主体。副标/装饰。比例` |
| 维度声明 | 背景之后必须声明 3D / 平面，严禁模棱两可 |
| 字形设计 | 必须有可见设计痕迹（连笔/延长/变形/错位）；用物理物象比喻笔画（如"流动液体""堆叠积木"），拒绝抽象形容词；字形≠材质 |
| 字间关系 | 禁止逐字孤立设计，须描述连接逻辑（连笔/穿插/共用笔画）或整体动势，字间距紧凑 |
| 装饰理性 | 默认优先字形元素置换（如星星替换点画）；仅用户明确要求时才加外部装饰；装饰须与主体有结构关联 |
| 色彩精准 | 明确主体色/描边色/装饰色；背景色严格遵循 Step 0 锁定值；仅 Step 0 无背景色时兜底：浅色字→纯黑背景，深色字→纯白背景；仿图模式未被 Step 0 覆盖的色彩跟随参考图 |
| 背景纯净 | `干净的纯{色}背景` 置于 Prompt 最前；{色} = Step 0 锁定色 > 自动推导色；光影（发光/投影/倒影）属主体层，不写入背景；所有装饰/特效必须收敛在文字主体范围内，严禁溢出到背景区域 |
| 排列与完整 | 默认**单行横向排列**，用户明确指定排列方式时从其要求；风格自带排列惯例（如印章→方阵、竖排书法→竖排）视为隐式指定；文字整体必须完整呈现在画面内，四周留有安全边距，严禁任何笔画被裁切 |
| 比例计算 | ≤2字→1:1，3-8字→4:3，>8字→16:9，置于 Prompt 最后；用户指定比例或构图方式时优先遵从（如四字1:1、竖排等）；风格自带比例惯例（如印章→1:1）视为隐式指定；无指定且无风格惯例时，比例必须匹配单行横排的文字数量，严禁将多字压缩为正方形构图 |

## 5. 禁忌

| 禁忌 | 说明 |
|------|------|
| 风格悖论 | 维度/材质/时代/物理不可混搭；用户强制要求时走融合策略（仿图模式跟随原图，无此限制） |
| 贴纸装饰 | 装饰必须融入设计，不可悬浮贴纸化 |
| 结构混乱 | 背景/主体/副标必须句号分隔，严禁逗号连接 |
| 风格漂移 | 3D字体≠3D插画，平面字体≠平面插画 |
| 文字粘连 | 复杂艺术字须保持文字结构可识别性 |
| 悬浮干扰 | 装饰不可遮挡文字核心识别区，不可无物理支撑悬浮 |
| 背景溢出 | 机械管线/藤蔓/光效/烟雾等装饰严禁从文字延伸到背景区域，背景必须保持纯净 |
| 文字裁切 | 文字整体必须完整处于画面安全区内，任何笔画/装饰不可超出画布边缘被裁切 |
| 多行堆叠 | 用户未指定排列时，严禁将文字堆叠为多行/方阵/竖排；用户明确要求特定排列方式时遵从 |
