# 小红书文字PLOG模板调研知识库

> 用途：作为「PLOG选题总监」智能体的知识集底座，沉淀文字PLOG模板的玩法分类、场景维度、模板化标准、禁用规则与输出字段。
> 重要：本知识库不放每周热点，热点由用户作为任务输入提供。

---

## 一、什么是文字PLOG模板

文字PLOG模板，是指可被普通用户直接套用、替换照片和文字、发布到小红书 / 朋友圈 / 抖音图文的图文封面或成组图设计模板。

特征：
- 视觉风格鲜明，识别度高
- 用户可替换主图照片
- 文字可后期编辑、可批量替换
- 模板可上架、可复用、可批量产出
- 适合用户分享情绪、生活、出行、追星、美食、节气

不属于文字PLOG模板：
- 完整海报（不易复用）
- 公众号封面（场景不同）
- 普通图文笔记（缺乏可套图结构）
- 超复杂艺术化字体（用户无法二次编辑）

## 二、两层结构：大主题 vs 小主题

每期工作流都遵循两层结构。

| 层级 | 定义 | 举例 |
|---|---|---|
| 大主题 | 玩法/视觉公式，决定整组模板的视觉表达 | 颜色+文字拼贴plog、上下文字plog |
| 小主题 | 同一大主题下的场景变体，构成系列 | 旅游出行场景、美食场景、节气场景 |

每期任务 = 1 个大主题 × 6-8 个小主题（场景变体）。

## 三、大主题清单（玩法/公式）

### 1. 颜色+文字拼贴plog
- 玩法定义：双图/四图色块拼贴 + 大字标题，ins风
- 适合场景：旅游出行、美食、城市漫游、节气
- 文案风格：中英文混排短句、地点+时间、慢生活语气
- 文字位置：上下夹 / 镂空叠加 / 色块上居中
- 视觉关键词：莫兰迪色块、四宫格、ins拼贴、复古色彩、留白
- 风险点：色块占比避免遮挡照片主体

### 2. 上下文字plog
- 玩法定义：单图，文字分上下两行夹画面
- 适合场景：日常碎片、旅行、节气
- 文案风格：长句陈述、慢生活语气、心情独白
- 文字位置：上+下
- 视觉关键词：留白、低饱和、生活感、自然光
- 风险点：文字行数和字号需统一规格

### 3. 变形文字小红书封面
- 玩法定义：大字变形作为视觉主体，照片作为衬底
- 适合场景：节气、活动、限定、主题
- 文案风格：节气词、限定词、活动主题词
- 文字位置：居中放大 / 撑满画面
- 视觉关键词：变形字、主题色、贴纸、夸张字形
- 风险点：变形字易识别度差，需保持基本可读

### 4. 手写体plog
- 玩法定义：手写字 + 生活照，亲切手账感
- 适合场景：日常、旅行、宠物、通勤
- 文案风格：随手记录、口语化短句、日记体
- 文字位置：右下 / 左上 / 镂空叠加
- 视觉关键词：手写字、星星音符、涂鸦、贴纸、马克笔
- 风险点：手写字版权与统一性

### 5. Color Weekly Plog
- 玩法定义：一周一主色调，多图组合，强调色彩统一
- 适合场景：日常碎片、城市漫游、生活方式
- 文案风格：周报感、合集感、Weekly短句
- 文字位置：色块上 / 居中标题
- 视觉关键词：单色调、Weekly、组图、风格统一
- 风险点：照片色调一致性要求高

### 6. 摄影花鸟字
- 玩法定义：单字与照片主体融合，字形即画面
- 适合场景：自然、节气、城市建筑、宠物
- 文案风格：单字情绪、节气词、氛围词
- 文字位置：居中 / 与主体融合
- 视觉关键词：单字、留白、艺术、镂空
- 风险点：字与画面融合度要求高，对设计能力有要求

### 7. 美食探店霓虹字封面
- 玩法定义：俯拍美食 + 霓虹/变形大字标题
- 适合场景：探店、咖啡、甜品、火锅、家常菜
- 文案风格：探店打卡、推荐感、生活仪式感
- 文字位置：居中大字 / 顶部横幅
- 视觉关键词：霓虹、菜单感、俯拍、餐桌纹理
- 风险点：避免出现真实品牌logo

### 8. 涂鸦手账风
- 玩法定义：贴纸+手写+涂鸦组合，少女手账感
- 适合场景：日常、教程、心情、生活
- 文案风格：教程感、轻松、好玩、记录感
- 文字位置：散点分布 / 镂空叠加
- 视觉关键词：贴纸、星星、爱心、马克笔、涂鸦
- 风险点：元素过多易杂乱，需控制密度

## 六、模板化判断标准

判断小主题是否值得做成模板，必须满足以下大部分条件：

| 判断项 | 通过标准 |
|---|---|
| 用户发布场景明确 | 能说出用户什么时候、为什么发 |
| 视觉风格稳定 | 有可复制的色彩、字体、构图特征 |
| 照片可替换 | 用户能用自己的照片直接套用 |
| 文字可编辑 | 后期能改标题、日期、地点、心情短句 |
| 可生成无文字背景 | 背景可独立产出，文字单独叠加 |
| 适合批量上架 | 能拆成系列模板，不是单一爆款 |
| 风险可控 | 不涉及敏感、版权、个人争议 |
| 平台传播性强 | 在小红书、朋友圈、抖音图文均能发 |

---

## 七、不建议做模板的方向

- 强人物肖像（涉及肖像权）
- 具体明星/IP（版权与平台风险）
- 涉敏话题（政治、宗教、地区争议）
- 医美/医疗效果对比
- 金融/投资类
- 教培类（合规风险）
- 极端情绪（抑郁、自伤等）
- 真实事件/灾难

---

## 八、风格元素禁用规则（生成prompt时必须避开）

- 不要生成乱码文字、伪英文、伪汉字
- 不要出现真实品牌logo
- 不要出现真实明星脸
- 不要出现敏感符号或地区争议元素
- 无文字背景必须明确：无任何字母、数字、文字、招牌、logo
- 留出明确的文字摆放区域
- 比例统一为 3:4（小红书优先）或 1:1（朋友圈/抖音通用）

## 九、模板交付字段标准

### 小主题初筛字段
| 字段 | 说明 |
|---|---|
| 编号 | 1-8 |
| 用途 | plog / 封面 / 拼贴 / 单图 / 多图 |
| 场景 | 旅游 / 美食 / 日常 / 节气 等 |
| 例图参考方向 | 颜色、构图、装饰元素描述 |
| 文案 | 中英文短句，25字内 |
| 文字位置 | 上 / 下 / 左 / 右 / 居中 / 镂空叠加 / 上下夹 |
| 视觉关键词 | 用于后续无文字背景生成 |

### 模板细化字段
| 字段 | 说明 |
|---|---|
| 选题名称 | 简短可识别 |
| 无文字背景方向 | 颜色、构图、风格、留白区 |
| 文字排版建议 | 主标题 / 副标题 / 日期 / 地点 / 心情短句 |
| 可替换内容 | 哪些素材是用户自己上传 |
| 风险提示 | 版权 / 合规 / 平台限流 |

## 十、AI背景生成提示词模板

### 通用必加约束（每条提示词都必须包含）
- no text, no letters, no numbers, no logo, no signage, no watermark
- empty space reserved for text overlay
- 比例：3:4 或 1:1
- 高质量、自然光、真实感

### 中文提示词模板
```
[场景]，[视觉关键词]，[色彩描述]，[构图描述]，[留白区域描述]，无任何文字、无logo、无招牌、无水印，留出文字摆放空间，3:4比例
```

### 英文提示词模板
```
[scene], [visual keywords], [color palette], [composition], [empty space for text], no text, no letters, no logo, no signage, no watermark, 3:4 aspect ratio, high quality, natural light
```

## 十二、使用方法说明

1. 本知识库属于长期方法论，不放每周热点。
2. 每周热点和小红书检索结果，由用户作为任务输入提供。
3. 智能体生成选题时，必须先确定大主题（玩法），再展开小主题（场景变体）。
4. 智能体在判断模板化价值、风险、输出字段时，必须依据本知识库。
5. 默认采用省token模式：表格优先、单元格不超过40字、不输出长篇推理。
6. 每轮结束必须给出「下一步需要用户确认什么」。
7. 知识库不作为热点来源，缺乏小红书检索时必须标注「待小红书验证」。
