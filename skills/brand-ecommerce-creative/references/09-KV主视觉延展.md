# Skill 09 · Campaign KV 主视觉延展

## 定位
KV 是一次 Campaign 的**视觉母体**：先定 1 张主 KV，再按延展规范
派生到所有渠道——本 Skill 是其他方向 Skill 的"上游"。

## 主 KV 构成要素
- 核心视觉符号（1 个，贯穿全渠道）+ Campaign 主题字 + 品牌 Logo 位 + 留白延展区
- 画布用**最大公约构图**：核心元素集中在中央 60% 安全区，四周为可裁切延展区

## 延展矩阵（一稿派生）
| 渠道 | 规格 | 延展规则 |
|------|------|---------|
| 社媒组图封面 | 3:4 | KV 竖裁 + 标题重排（调 Skill 01） |
| 电商 banner | 平台规格 | KV 横裁 + 利益点条（调 Skill 03/04） |
| 直播背景 | 定制 | KV 放大做氛围底（调 Skill 05） |
| 信息流素材 | 16:9 / 9:16 | KV 元素重组 + 3 秒卖点（调 Skill 06） |
| 朋友圈/裂变海报 | 3:4 / 9:16 | KV + 二维码模块（调 Skill 07） |
| 线下海报/易拉宝 | A1 / 80×200 | KV 高清重输出 CMYK（调 Skill 08） |

## 延展一致性清单
- 核心视觉符号在每个延展物上出现且不变形
- 主题字字体/颜色全渠道一致；Logo 位与安全区按品牌规范
- 各渠道只允许"裁切与重排"，不允许"重新设计"

## 强制核对（H0/H1 节点）
- Campaign 主题字（法务核名）、KV 人物/素材授权范围（含线下与投放）
