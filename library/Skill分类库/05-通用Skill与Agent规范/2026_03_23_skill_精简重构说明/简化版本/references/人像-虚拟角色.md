# 虚拟角色生成特征

当用户指明虚拟形象需求（3D、动漫、卡通、虚拟IP）时读取本文件。虚拟角色的**风格质感**遵循本文件，**动作场景**遵循对应赛道人像文件。

## 3D 萌系风格
- 特征：3D渲染，大眼萌系，夸张表情，柔和光照，细腻材质（毛发/布料）
- 适用：情感故事、亲子教育、轻松科普
- Prompt关键词：`3D萌系风格, 3D渲染, 可爱, 大眼睛, 夸张表情, 柔和光照, 细腻材质`

## 韩系卡通
- 特征：线条简洁流畅，清新淡雅莫兰迪色系，时尚穿搭，扁平化或微立体
- 适用：穿搭分享、美妆教程、生活Vlog封面
- Prompt关键词：`韩系条漫风格, 扁平插画, 简洁线条, 清新淡雅配色, 时尚穿搭, 极简主义`

## Emoji/Memoji 风格
- 特征：苹果Memoji风格，头部比例大，表情生动，背景纯净或高饱和
- 适用：知识口播、个人IP头像、情绪表达
- Prompt关键词：`Memoji风格, 3D头像, 表情生动, 纯净背景, 图标风格`

## 美式复古漫画
- 特征：波普艺术，粗轮廓线，高饱和撞色，网点纹理
- 适用：职场吐槽、犀利观点、复古潮流
- Prompt关键词：`美式复古漫画风格, 波普艺术, 粗线条轮廓, 半色调网点, 复古高饱和配色, 对话气泡`
