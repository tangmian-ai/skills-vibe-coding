# 复合运镜与组合技巧 (Compound Camera Movements)

## 一、经典组合运镜

### 1. 推 + 升 (Dolly In + Crane Up)
- **效果**：靠近主体的同时视角升高，产生史诗感
- **适用**：人物揭示、建筑展示、情绪高潮
- **提示词**：`dolly in while craning up`

### 2. 拉 + 降 (Dolly Out + Crane Down)
- **效果**：远离主体同时降低视角，产生结束/告别感
- **提示词**：`pull out while descending`

### 3. 跟随 + 环绕 (Track + Orbit)
- **效果**：跟随主体移动的同时缓慢环绕
- **适用**：动作场景、角色展示
- **提示词**：`tracking orbit shot`

### 4. 推 + 摇 (Dolly In + Pan)
- **效果**：靠近的同时水平旋转揭示新元素
- **提示词**：`dolly in with pan reveal`

### 5. 横移 + 推 (Truck + Push)
- **效果**：侧面移动逐渐转为正面推进
- **提示词**：`lateral tracking transitioning to dolly in`

### 6. 升 + 环绕 (Crane Up + Orbit)
- **效果**：螺旋上升，电影级揭示
- **提示词**：`ascending spiral orbit`

### 7. 希区柯克变焦 (Dolly Zoom / Vertigo Effect)
- **效果**：推镜头同时反向变焦，背景扭曲但主体大小不变
- **适用**：恐惧、眩晕、顿悟时刻
- **提示词**：`dolly zoom`, `vertigo effect`, `zolly`

### 8. 降 + 推至特写 (Crane Down + Push to Close-up)
- **效果**：从高处降落并推进到人物面部
- **提示词**：`descending push to close-up`

## 二、运镜节奏模式

### 静-动-静 (Hold-Move-Hold)
先固定→运动→再固定。最常见的运镜节奏，给剪辑留出入出点。

### 动-静 (Move-Hold)
运镜开场后停在关键画面。适合揭示型镜头。

### 静-动 (Hold-Move)
固定画面后开始运动。适合反应镜头、离开场景。

### 加速-减速 (Ease In - Ease Out)
运镜起止带缓动曲线，避免机械感。AI提示词中用 `smooth acceleration` 描述。

### 匀速 (Constant Speed)
全程匀速运动，工整感强。用 `constant speed` 或 `linear movement` 描述。

## 三、运镜情绪对照表

| 情绪/氛围 | 推荐运镜组合 | 速度 |
|----------|-------------|------|
| 紧张/悬疑 | 缓推 + 微晃动 | 慢 |
| 震撼/史诗 | 航拍拉升 + 环绕 | 中→慢 |
| 亲密/温馨 | 缓推至近景 + 浅景深 | 慢 |
| 混乱/战斗 | 手持晃动 + 快速甩 | 快 |
| 揭示/惊喜 | 摇镜头揭示 / 升降揭示 | 中 |
| 孤独/忧伤 | 缓拉至远景 + 固定 | 慢 |
| 欢快/活力 | 跟随 + 快速横移 | 快 |
| 庄严/仪式 | 缓慢升镜头 + 对称构图 | 极慢 |
| 恐惧/不安 | 希区柯克变焦 / 滚转 | 中 |
| 日常/真实 | 手持轻晃 + 跟随 | 中 |

## 四、转场运镜衔接技巧

### 甩接甩 (Whip-to-Whip)
A镜头甩出 → B镜头甩入，利用运动模糊无缝衔接。

### 推入黑→拉出黑
A镜头推入纯黑区域 → B镜头从黑色拉出，产生前景遮挡效果。

### 匹配运动方向
A镜头向右横移 → B镜头继续向右横移，运动方向一致产生流畅感。

### 升降衔接
A镜头升到天空 → B镜头从天空降到新场景。

### 环绕衔接
A镜头环绕主体到背后 → 切换 → B镜头从正面环绕开始。
