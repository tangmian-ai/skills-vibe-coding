# C6 · 组图系列一致性

## 目标

组图必须同时满足：并排时一眼属于同一系列，翻页时每张都提供新的用户价值。

统一不是复制。只锁一个显性锚点，其余一致性通过隐性设计系统维持。

## 候选锚点来源

视觉 Agent 先从以下来源生成 3–5 个候选，不允许直接套固定答案：

1. 已提供 VI：品牌色、品牌图形、字体动作、摄影语言。
2. 上传产品：产品主色、材质、轮廓、结构细节、典型使用动作。
3. Brief 语义：活动概念、核心动词、传播比喻、功能路径。
4. 品类行为：食品的流动/层次、服装的廓形/面料、科技产品的光路/结构、家居的空间/舒适感。
5. 文案结构：同一主标题、章节编号、重复句式或统一标签；仅当它不会削弱逐页价值时使用。

平台品牌色、虚构 Logo、未经确认的参数或无关流行风格不得成为候选。

## 评分与选择

每个候选按 1–5 分评估：

- `evidence_strength`：是否来自真实 VI、商品或 Brief。
- `recognition`：缩略图并排时是否可识别。
- `extendability`：能否在不同场景、镜头和版式中变形延展。
- `message_relevance`：是否与核心卖点或传播概念有关。
- `non_interference`：是否不会抢夺每页主信息。
- `production_stability`：图像模型是否容易稳定复现。

总分最高者成为唯一 `selected_signature`。若前两名相差小于 2 分，优先选择证据更强、形态更简单、不会迫使六页同构的候选。

### 判断流程

1. 先识别不可改变的事实：品牌 VI、商品身份、已确认文案、平台规范。
2. 再从事实中抽取可视候选，不从方向模板预设颜色或构图。
3. 淘汰只能在一页成立、会遮挡核心信息、需要虚构资产或难以稳定复现的候选。
4. 对剩余候选评分，只锁定一个显性锚点。
5. 将选择结果连同候选、评分和理由交给 H1；设计师可改选，但系统不得替用户静默改写。

## 显性锚点

只允许选择一类：

- `color-light`：同一色相、切面光、渐变或光路。
- `graphic-device`：同一线条、框线、波形、几何切片或标注动作。
- `material`：同一纸张、金属、玻璃、织物或颗粒质感。
- `shape-silhouette`：同一产品轮廓、局部结构或容器形态。
- `title-lockup`：同一主标题或字组动作，不等于每页文字完全相同。
- `photographic-language`：同一焦段、光线、色彩科学或空间尺度。

锚点在每页可以改变大小、位置和具体形态，但必须保留可识别的色相、方向、材质或运动逻辑。

## 隐性不变量

模型再选择 3–4 个隐性约束：字体角色、基础网格、安全区、页码、材质精度、阴影逻辑、产品保真或 Logo 安全区。它们维持品质，但不能成为第二个显性主题。

### H1 辅助色彩也由模型决策

无论显性锚点是否选择颜色，H1 都必须根据当前证据输出 `support_palette`：

- `source`：明确说明来自 VI、上传产品、Brief 语义或 H0 文案，不得写“行业默认”。
- `tonal_strategy`：高键/中键/低键、清透/克制/浓郁等整体明度和饱和度策略。
- `base_field`：承载内容的基础色域，用定性语言描述。
- `accent_behavior`：强调色出现在哪里、占比多大、承担什么信息角色。
- `contrast_logic`：文字、主体、背景之间如何建立可读层级。
- `focal_energy`：主导有彩色族如何以足够面积和亮度覆盖核心主体、互动/使用路径与结果表面；不能退化为全灰画面上的孤立点色，也不能扩散成第二主题。
- `depth_logic`：如何通过明暗、材质、前后景、反射或实体阴影建立至少三级空间层次。
- `avoid`：与品牌、产品或传播语义冲突的颜色倾向。

禁止把“AI = 蓝青”“SaaS = 蓝紫”当成默认规则；没有 VI 时也不得编造精确 HEX/RGB/HSL。清爽不等于全灰、发白、低彩度或低对比，必须同时保留焦点色彩能量、清晰明暗层级和可感知空间深度。`avoid` 只描述应规避的色彩/对比倾向，不擅自禁用玻璃、金属等材质。若 `selected_signature.type` 是 `color-light`，色彩可以成为唯一显性联系；否则它只作为安静的 H1 支撑系统，不能抢成第二个显性主题。

## 逐页延展

每页都输出：

- `audience_value`：这一页给大众的新价值。
- `hero_task`：唯一主视觉要证明什么。
- `layout_skeleton`：版式骨架。
- `variation_axes`：本页相对前页必须变化的场景、镜头、信息密度或构图。
- `signature_expression`：同一锚点在本页如何出现。

相邻两页不得同时复用相同主视觉镜头、版式骨架和信息密度。六张完整组图应覆盖认知、问题、核心能力/利益、使用或证明、一致性/适配、转化收口；少于六张时按任务优先级合并，不重复填充。

### 显性联系之外的延展

显性锚点只负责“认出是同一组”，不能承担每页全部内容。其余变化由页面价值驱动：

- 用户价值：每页回答一个不同问题，例如是什么、为什么需要、如何工作、能得到什么、是否可信、下一步做什么。
- 主视觉任务：场景展示、功能证明、结构特写、步骤解释、对比或结果证明中择一，不重复同一种证明方式。
- 镜头与空间：全景、半景、微距、俯视、界面演示、人物交互按内容切换。
- 版式骨架：中心聚焦、非对称锁定、图文咬合、模块网格、能力云、分镜或数据图解按任务选择；6 页至少使用 4 种骨架。
- 信息密度：封面低密度抓注意，中段按解释任务升降，CTA 页重新收束；不能六页都像同一张封面。

结果应形成“一个记忆点 + 六个不同价值”，而不是“六张同模板换背景”，也不是“六种风格拼盘”。

### 明确风格要求的处理

用户追加的「电影科技光效」「清爽交互 3D 人物」等描述，是本组候选生成和评分的艺术边界，不直接替系统决定显性锚点。H1 仍须从 Brief/H0/VI/商品事实中选择一个 `selected_signature`，并说明它如何在该风格边界内跨页复现。

无论选择何种风格，软件/服务的语义主角不得被替换成儿童积木、玩具或无关硬件。机器人/人物只有在执行输入、反馈、编排或输出动作时成立。所有「输出结果」必须是可辨识的真实商业成品图，而不是图标、图表、线框或占位卡。若这些成品嵌在一张主海报内作为小预览，使用摄影主体、场景、光影和构图证明其真实感，但绝不在小预览中生成可读标题、卖点、活动信息、商品文案或界面标签；全页可读文字只能来自 H0 封闭文字集。

文字安全区作为隐性硬约束跨页锁定：左右 8%、顶部 12%、底部 16%；任一必需文字、页码或 CTA 被裁切、贴边、压缩、弯曲或刻在曲面上，整页打回。
