# 名称
内容创作 Skill 通用模板

# 描述
结合运营与设计规则，生成高质量图片生成 Prompt 的标准化 Skill

# 技能规范
> **使用说明**：在使用此模版创建新技能前，**必须**先阅读并理解 [参考文件/技能规范.md](file:///Users/yiming/Desktop/skill模版/参考文件/技能规范.md) 中的所有撰写规范与执行约束。

## 全局强制指令
你必须严格、从上到下、逐字阅读并执行文档中的【每一条指令】与【每一个步骤】。
严禁跳过任何环节（特别是指令中要求加载 `参考文件/` 文件的动作），严禁凭借自身知识进行“偷懒”或“脑补”。必须确保 100% 遵守所有被触发的规则。

## 步骤 0：解析用户输入与识别意图
请按下列逻辑解析用户输入，明确任务类型并提取关键变量：

1.  **识别场景与模式**（决定后续使用哪套 Prompt 框架）：
    - **分析输入内容**：是否有图片？有几张？文本包含什么关键词？
    - **判定任务场景**：
        - **文生图**：仅有文本 -> 需全量生成画面。
        - **文+图生图**：
            - **单图**：如“商品图+文案” -> 需保持商品主体，生成背景。
            - **多图**：如“风格参考图+商品图” -> 需进行风格迁移或融合。

2.  **提取显式变量**（用户明确指定的内容）：
    - **图片资源**：商品图、参考图、人像照等。
    - **文本指令**：主体描述、特定文案（如“5折”）、指定风格（如“极简”）、指定场景（如“春节”等）、改图要求（如“人物要正面”）。

3.  **识别待填充槽位**（用户未提及但框架必须的要素）：
    - 检查 Prompt 框架中哪些要素用户未指定（如：光影、构图、具体装饰元素），标记为**[待填充]**。

## 步骤 1：动态加载参考知识
根据步骤 0 识别到的场景和关键词，**必须**读取 `参考文件/` 下对应的规则文件，作为填充 Prompt 的知识源。

- **场景/风格知识**：
    - 识别到“春节/大促” -> 加载 `参考文件/主题文案库.md`（获取节日视觉元素）。
    - 识别到“极简/科技” -> 加载 `参考文件/通用设计原则.md`（获取对应的配色、构图规则）。
- **规范与限制**：
    - 涉及具体投放渠道 -> 加载 `参考文件/渠道规范合集.md`。
- **视觉素材**：
    - 需要背景描述 -> 加载 `参考文件/场景预设库.md`。
    - 需要人物姿态 -> 加载 `参考文件/人像姿态指南.md`。
- **风控底线**（全局必选）：
    - **必须**加载 `参考文件/通用禁用词.md`。

## 步骤 2：加载 Prompt 结构框架
**注意**：此步骤用于确定 Prompt 的骨架。

1.  **加载框架**：根据步骤 0 判定的场景（文生图/商品图/人像等），从 `参考文件/` 中读取设计师预设的高质量 Prompt 结构框架。
    - *示例框架*：`[主体描述] + [环境/背景] + [光影/氛围] + [风格修饰词] + [构图视角] + [画质参数]`
2.  **解析槽位**：识别框架中定义的各个子维度（如“光影”、“构图”），这些即为后续需要填充的**目标槽位**。

## 步骤 3：智能扩写与槽位填充
**这是核心步骤**。请基于加载的参考文件，对步骤 2 框架中的各个槽位进行智能补全。

1.  **意图扩写**（将抽象概念转化为视觉语言）：
    - *示例*：用户输入“春节氛围” -> 基于参考文件扩写为“红色背景, 金色祥云纹样, 喜庆灯笼, 暖色调光影”。
    - *示例*：用户输入“科技感” -> 基于参考文件扩写为“深蓝色渐变背景, 发光线条, 金属质感, 悬浮构图”。

2.  **槽位填充**（规则：用户输入 > 参考文件推荐 > 默认值）：
    - **主体槽位**：优先填入用户提供的图片描述或文本主体。
    - **环境槽位**：若用户未指定，从 `场景预设库.md` 中选择最适配当前风格的场景填入。
    - **光影/构图槽位**：若用户未指定，根据 `通用设计原则.md` 中的风格建议自动填充。

3.  **结构化组装**：将填充好的内容按步骤 2 的框架顺序组合，生成最终的 Prompt。

## 步骤 4：自检与修正
在输出前进行最终检查：
1.  **完整性检查**：确认 Prompt 框架中的核心要素（主体、风格、环境）均已有具体内容，无空缺。
2.  **冲突消解**：检查扩写的内容是否与用户原始指令冲突？（如用户要“极简”，扩写中却包含“繁复花纹”，需修正）。
3.  **合规审查**：再次扫描 `参考文件/通用禁用词.md`，确保生成的 Prompt 不含违禁词。

## 步骤 5：最终输出
请严格按照以下格式输出 Prompt 结构化结果：

### 生成结果
**Prompt 列表**（若为单图则仅 1 条）：

1.  **[图片序号/场景名]**：
    - **Prompt**：[主体]...[环境]...[风格]...[尺寸]...
    - **负面提示**：[可选] 水印，文字
    - **参数说明**：[可选] 比例、分辨率等

- **负面提示**：[可选]
- **参数**：[可选]

   - **Prompt**：[主体] + [场景 A 描述] + ...

   - **Prompt**：[主体] + [场景 B 描述] + ...

## 步骤 6：图片生成
**注意**：此步骤需调用具体的生图工具（如 seedream4.5、seedream5.0 或 nanobanana pro）。

1.  **选择工具**：根据用户需求或默认配置，选择合适的生图模型。
2.  **执行生成**：将步骤 5 生成的 Prompt 传入选定的工具进行图片生成。
3.  **结果展示**：将生成的图片展示给用户。
4.  **通用指令**：调用生图工具前先阅读 image-generation Skill。利用最终填充完整的 Prompt，**直接调用 XXX 模型**进行生成，（“XXX”为轻舟配置的模型code）。
