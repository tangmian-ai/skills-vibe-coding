# Skill C5 · 艺术字与字体设计

## 路由逻辑

1. **纯推理**判断氛围（禁止调用 scene_tool 等虚构工具）
2. 读取对应 Reference 的字形/材质/反悖论要求
3. `tools/typography_design.mjs` 输出 `TypographySpec`（含 `reference_file`）
4. **默认**：`buildC5ReverseTypographyImagePrompt()` 写入逐页生图 Prompt，**模型在画面内渲染艺术字**
5. **兜底**（仅 `USE_SCENE_OVERLAY=1`）：`font_registry.mjs` + `render_s01_text_overlay.py` 程序叠字

## 与各方向协作

- **节日模板 S02**：主标题**必走** C5
- **私域微信 S06**：熟人转化标题，偏温和信任感，保留二维码/行动指令安全区（见 `06-私域微信生态.md`）
- **社媒 S01**：封面 Hook，原生感，避免过度立体促销字

## 不触发

- 用户带参考图要求「模仿图中文字风格」→ 走 **C3 反推**，不走 C5 重新设计
