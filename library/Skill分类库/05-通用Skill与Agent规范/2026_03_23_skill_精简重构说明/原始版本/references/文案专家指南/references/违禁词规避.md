# 违禁词规避原则 (严禁触犯)

你需要严格遵守以下小红书平台内容安全规则，在生成封面文案时自动规避相关风险表达。

## 【一】禁止任何形式的平台导流
- **禁止出现**：其他平台名称、联系方式（手机号、微信、V信、WX、QQ、二维码、地址）、搜索引导（去搜、🔍、下载、免费试用等）、点头像、看主页、私信我等引流黑话。

## 【二】禁止交易引导类表达
- **禁止出现**：购买、下单、秒杀、清仓、加盟、代理、店铺、活动时间、箭头或引导性符号。
- **安全替代**：分享经验、思路拆解、方法整理、个人总结。

## 【三】价格表达限制
- **禁止出现**：明确价格、金额数字、低价暗示、价格对比。

## 【四】禁止时限刺激用语
- **禁止出现**：仅此一次、随时涨价、马上结束、最后一波、立刻行动、现在不做就晚了。

## 【五】避免营销钩子黑话
- **禁止出现**：私我、看我主页、评论区领、点头像、资料免费送。

## 【六】避免封面视觉暗示营销
- **禁止出现**：箭头符号、强引导图形语言、促销型标题结构。
- **原则**：表达应偏内容分享，而非交易转化。

## 【七】整体风格安全要求
- 像内容分享，而非商业广告
- 避免强营销语气、利益承诺、站外引导、交易暗示

## 【八】其他高风险红线 (综合补充)
- **绝对化词汇**：禁止使用“最”、“第一”、“绝对”、“100%”、“顶级”等违反广告法的极限词。
- **过度夸张承诺**：禁止使用“暴富”、“日赚xx万”、“躺赚”、“逆天改命”等不切实际的承诺。
- **保证类表达**：禁止使用“包过”、“包教包会”、“无效退款”等保证性承诺。

## 【九】自媒体起号与变现敏感词
- **起号类**：禁止出现“起号”、“养号”、“快速涨粉”、“涨粉”、“流量密码”、“模仿博主”、“对标账号”、“新手做号”、“从0到1做号”、“账号权重”、“限流”。
- **变现类**：禁止出现“变现”、“赚钱”、“搞钱”、“接广告”、“接广”、“月入过万”、“副业”、“收入”、“商单”、“合作”、“蒲公英”。
- **爆款/同质化类**：禁止出现“爆文密码”、“爆文公式”、“万能标题模板”、“关键词攻略”、“套用模板”、“一键生成”、“写作套路”、“抄”。

## 【十】AI生成与作弊行为
- **AI作弊**：禁止出现“洗稿”、“AI代写”、“过度强调AI生成”（暗示低成本量产）。
- **AI获利**：禁止出现“AI起号”、“AI赚钱”、“AI盈利”、“AI网赚”。
- **AI侵权**：禁止暗示“用AI生成真人形象迷惑用户”、“利用AI魔改恶搞影视作品”。

## 【十一】诱导不良互动
- **心理暗示**：禁止出现“双击有惊喜”、“不点赞不是中国人”、“点关注救奥特曼”。
- **虚假元素**：禁止在封面中加入“虚假按钮”、“伪造的暂停键”等误导点击。
- **福利换关注**：禁止出现“扣666领课件”、“抽一位粉丝送xx（需关注+评论）”、“揪3人”。
- **玄学引导**：禁止出现“接不接”、“接好运”、“接接”、“玄学好运/祈愿/正能量”等无意义互动。

## 【十二】医疗美容细分红线
- **医疗术语**：禁止出现“治疗”、“药”、“处方”、“医用”、“消炎”、“抗菌”、“抗敏”、“祛疤”、“修复疤痕”。
- **减肥瘦身**：禁止出现“减肥”、“瘦身”、“瘦脸”、“吸脂”、“燃脂”、“刮油”、“三天瘦五斤”、“XX天瘦XX斤”。
- **美容整形**：禁止出现“丰胸”、“增高”、“整容”、“微整形”、“隆鼻”、“永久脱毛”。
- **护肤强断言**：禁止使用绝对化功效词，如“美白”、“祛斑”、“抗衰”、“除皱”、“生发”、“防脱”。

## 【十三】其他违法违规与功能限制
- **违法违规**：禁止出现“翻墙”、“vpn”、“代考”、“假货”、“高仿”、“刷单”、“非法集资”。
- **功能诱导**：禁止出现“水印”、“二维码”、“vip”、“限免”、“免费”等功能性诱导词。

如出现疑似风险表达，必须自动优化为安全表达版本。
