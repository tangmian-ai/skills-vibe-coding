# Skill 05 · 直播间视觉

## 物料清单
| 物料 | 尺寸 | 要点 |
|------|------|------|
| 直播预告海报 | 3:4 / 9:16 | 时间 + 主播 + 利益点三要素，时间字号第二大 |
| 直播封面 | 1:1 / 16:9 | 人脸/产品优先，文字 ≤8 字（列表页极小） |
| 直播间背景板 | 按间距定制 | 品牌色大色块 + 循环利益点，忌细节纹理（摄像头糊） |
| 贴片/角标 | 9:16 内挂件 | **必须避开平台 UI 安全区**（点赞/评论/购物车/弹幕区） |
| 商品讲解卡 | 1:1 | 一卡一品：价格区 + 卖点 ≤3 条 |

## 默认 3 张画面结构
| 页 | 画面任务 | 注意 |
|----|----------|------|
| P1 直播预告 | 产品 Hero + 开播时间 + 预约 CTA | 像预告，不是详情页；时间和利益点必须远距可读 |
| P2 直播背景板 | 产品/品牌氛围 + 主播安全区 | 中央或一侧留出主播位置，避免文字被人挡住 |
| P3 商品讲解卡 | 卖点拆解 + 细节特写 + 进房 CTA | 一卡只讲一个商品，卖点 ≤3 条，适合主播指读 |

> 直播视觉必须按商品读图改画面，不能把详情页或电商主图直接裁进直播包。预告页偏吸引预约，背景板偏主持人口播安全区，讲解卡偏单卖点指读；产品只保留一个主视觉，除非讲解卡明确需要局部特写或对比小图。

## 平台安全区（关键差异）
- 抖音：底部 25% 弹幕评论区、右侧图标列——贴片放**上 1/3 中央偏左**
- 视频号：顶部状态栏 + 底部互动区，左下角商品浮层位预留
- 淘宝直播：右下宝贝口袋、左下评论——角标放右上

## 可读性规则（观看距离 ≠ 手机浏览）
- 直播间内文字比社媒物料**放大 1.5~2 倍**；对比度优先于精致感
- 价格数字用品牌色最重字重；机制文案（满减/赠品）分行不叠行

## 强制核对（H0 节点）
- 直播时间（含时区/场次）、价格机制、赠品数量、主播肖像授权
