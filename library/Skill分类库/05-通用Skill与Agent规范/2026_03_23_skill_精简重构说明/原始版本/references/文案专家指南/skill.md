# 文案专家指南 Skill

本 Skill 旨在为小红书封面提供爆款文案策略、赛道匹配及违禁词规避服务。

## 1. 核心任务流程

Agent 在执行文案生成任务时，应遵循以下流程：

1.  **Analyze（分析）**：识别用户输入的赛道和主题核心。
2.  **Match（匹配）**：根据赛道类型，调用 `references/赛道策略/` 下的对应文件，获取最佳语气和爆款公式。
3.  **Construct（构建）**：利用爆款公式重组内容，并按照 `1. 封面文案要求` 进行拆解。
4.  **Check（自查）**：调用 `references/违禁词规避.md`，执行严格的违禁词规避检查。

## 2. 封面文案要求

- **🎨 同款封面复刻 (模式 A)**：**字数严格对齐**。
  - **主标题**：生成的文案字数必须与参考图2的主标题字数**完全一致**。
  - **副标题**：生成的文案字数必须与参考图2的副标题字数**完全一致**。
  - *示例*：若参考图2主标题为“大学生活指南”（6字），用户主题为“职场”，则生成的主标题必须为6个字（如“职场小白指南”）。
- **✍️ 博主风封面定制 (模式 B) / 💬 虚拟IP封面定制 (模式 C)**：
  - 字数 6–15字，最优控制在12个字以内
  - 适合直接放在封面视觉上
  - 强结论 / 强钩子 / 强情绪
  - 有网感但不过度营销
  - 像真实博主表达
